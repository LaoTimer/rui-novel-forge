# 写作技巧（Writing Techniques）

> 本文件整合对话/动作/感官/留白/主题/伏笔/心理描写等核心技法（共 11 节），配合 spec 使用，是写好正文的技法库。

## 1. 对话创作（5 步工作流 + 22 条军规）

### 5 步工作流

```
Step 1 锚定欲望（说出口的 vs 不愿承认的）
Step 2 设计策略（用什么方法达成，说什么藏什么）
Step 3 选冲突类型（均衡/不对称/非直接/自反性/微限/喜剧）
Step 4 写节拍序列（拆成动名词对）
Step 5 落到文字（用角色专属词汇写）
```

### 提示语替代四招（治"对话癌"）

> **满篇"某某说/某某道"是文笔稚嫩最直接的证据**。角色像一群对着剧本念词的木偶，代入感归零。四招按"外部 → 内在"递进：动作卡位（动作带声）→ 神态神韵（表情带声）→ 情境穿插（环境带声）→ 语感辨识（语言自带声）。口诀：**能用演的，就不要用讲的。**

#### 招式 1：动作卡位法（动作带声）

- **核心**：删掉"说"，用一个角色专属动作承担"谁在说话"的职责，同时传递情绪与压迫感。
- **反模式**：❌ "林动一脸愤怒地说：你竟然敢动我妹妹。"（平铺直叙）
- **正例**：✅ "林动猛地跨出一步，脚下的青石板瞬间崩碎，他死死盯着林琅天：你竟然敢动我妹妹。"（零个"说"，怒火和压迫感全出来）
- **适用**：冲突、对峙、情绪爆发。
- **要点**：动作要"专属"：这个人会做、别人做不出的动作。动作越具体，情绪越烈。

#### 招式 2：神态神韵法（表情带声）

- **核心**：细腻情感戏用眼神、微表情代替"说"，靠细节让读者自己沉浸。
- **反模式**：❌ "苏清月害羞地说：其实，我也挺喜欢你的。"（太干）
- **正例**：✅ "苏清月低下了头，发丝遮住了红透的耳根，她绞着衣角，声音细若蚊虫：其实，我也挺喜欢你的。"（红耳根、绞衣角，暧昧氛围自己长出来）
- **反派示例**：❌ "他阴险地说：这次你跑不掉了。" → ✅ "他嘴角勾起一抹残忍的弧度，目光像毒蛇一样锁死对方：这次你跑不掉了。"（画面感 + 可勾勒的脸）
- **适用**：情感戏、暧昧、反派、心理暗战。
- **要点**：微表情越具体越好（耳根红 / 嘴角弧度 / 手指绞衣角）；禁止"阴险地""生气地"这类贴标签副词（联动 check_quality.py 副词专项）。

#### 招式 3：情境穿插法（环境带声）

- **核心**：用周围的物品、天气、背景声音打断对话，制造"空镜头"，给读者喘息和想象的空间，同时自然避开重复提示语。
- **反模式**：❌ 他问：你真的要走吗？她说：是的。他问：还会回来吗？（灾难，电报体）
- **正例**：✅ 他抬起头，任由冰冷的雨水冲刷着眼眶：你真的要走吗？远处破旧的绿皮火车发出一声凄厉的长鸣，淹没了所有的回响。她沉默了很久，才轻轻吐出两个字：是的。他自嘲地笑了笑，目光穿透雨幕，看向那延伸到黑暗尽头的铁轨：还会回来吗？（雨水、鸣笛、铁轨，对话有了呼吸感）
- **适用**：离别、转折、情绪高潮。
- **要点**：环境要素必须"在场"（场景里本来就有的雨水/鸣笛/铁轨），不是硬塞道具；穿插位置 = 情绪需要停顿的地方。

#### 招式 4：语感辨识法（语言自带声，最高境界）

- **核心**：角色语言逻辑（口头禅 / 句式节奏 / 词汇偏好）独一无二时，提示语可完全省略，像电影剧本一样干净，读者闭眼不认错人。
- **示例**：猪八戒开口"俺老猪"，阿Q开口"我手执钢鞭将你打"，不需要"猪八戒说"。
- **实践路径**：
  1. 给角色定"语言指纹"：有人简短有力（"滚。"），有人爱掉书袋（"依本官所见……"），有人阴阳怪气（"哟，这不是……"）
  2. 群像戏 / 双人对峙时，连续 3-5 句无提示语切换，靠语言指纹区隔
  3. 验证 = 下方"声音指纹互换测试"：遮名字仍能辨 → 成功
- **适用**：群像戏、双人对峙、高辨识度配角。
- **要点**：与 05 声音指纹 4 清单（会用名词/动词/修饰/禁用词）联动；语感辨识是 4 清单的"台词面"。

#### 使用边界（避免矫枉过正）

- "说/道"是**隐形词**，不是禁用词。
- 快节奏博弈 / 快速交代信息时，用"说"最高效，不分散读者注意力。
- **真正的忌讳是连续重复**：一页（约 300-500 字）超过 10 个"说/道"，读者视觉疲劳。
- 任务不是"消灭说"，是把**平淡重复的"说"**替换成带情感色彩的动作、神态、环境。

#### 四招速查

| 招式 | 用什么带声 | 适用场景 | 一句话口诀 |
|------|-----------|---------|-----------|
| 动作卡位 | 专属动作 | 冲突 / 对峙 / 爆发 | 动作越具体，情绪越烈 |
| 神态神韵 | 眼神 / 微表情 | 情感 / 暧昧 / 反派 | 能用演的，就不要用讲的 |
| 情境穿插 | 物品 / 天气 / 背景声 | 离别 / 转折 / 高潮 | 环境是对话的呼吸 |
| 语感辨识 | 语言指纹 | 群像 / 对峙 / 配角 | 遮名能辨 = 成功 |

### 22 条对话军规

#### 基础篇（6 条）

1. **目的明确法则**：每句对话都有任务（推动/塑造/透露）
2. **自然口语法则**：写完读出声，书面语改口语
3. **独特声音法则**：角色声音不同
4. **冰山法则**：90% 意思藏在表面下
5. **动作配合法则**：配合动作/表情
6. **简洁为王法则**：没人一口气说三段不带喘

#### 进阶篇（8 条）

7. **冲突驱动法则**：即使情侣聊天也藏着对抗
8. **节奏控制法则**：像乒乓对决，有来有回
9. **信息滴灌法则**：切忌角色互说已知事
10. **情绪优先法则**：情绪 > 信息
11. **环境烘托法则**：紧张时写雨点
12. **留白艺术法则**：沉默 > 千言
13. **方言俚语慎用法则**：提示即可，不炫技
14. **声音辨识法则**：遮名字能辨角色

#### 高级篇（8 条）

15. **潜文本深度法则**：3 秒直觉能猜到
16. **冲突类型多变法则**：不全是均衡冲突
17. **首句行动法则**：第一句是挑衅/悬念
18. **声音指纹专属法则**：每角色有 4 清单
19. **对话密度法则**：该用对话就用，该留白就留
20. **声音心理法则**：紧张时短句，平静时中长句
21. **对话收尾法则**：不要每次都"主角说完离场"
22. **无声胜有声法则**：关键场景可以完全无对话

> **军规实操入口**：军规 5（动作配合）/ 11（环境烘托）/ 14（声音辨识）/ 22（无声胜有声）落到文字时怎么操作？→ 见上方"提示语替代四招"。

### 五大对话死法

| 死法 | 症状 | 改法 |
|------|------|------|
| 强行解说型 | 角色互说已知事传设定 | 信息在冲突中释放 |
| 无行动闲聊型 | 对话纯粹消耗字数 | 每句标动名词 |
| 过度滥情型 | 语言比情感夸张 | 大事件用克制表达 |
| 角色声音雷同 | 遮名字分不清 | 建立专属词汇库 |
| 过于明白型 | 角色说出作者才知道的事 | 藏潜文本 |

> **⚠️ 第 6 大死法（最常见）：提示语癌**。满篇"某某说/某某道"，角色像念剧本的木偶。改法 → 提示语替代四招（动作卡位 / 神态神韵 / 情境穿插 / 语感辨识）。检测 → check_quality.py 提示语密度。

### 声音指纹的互换测试（核心检验）

**示例**：
```
A: "我若不愿，天地又能奈我何。"
B: "哎呦喂，这可咋整呢。"
C: "依本官所见，此事尚有蹊跷。"

A 是林修远（古风/不屈）
B 是王翠花（东北/市井）
C 是县令（官员/文言）

遮掉名字仍能辨 → 声音指纹成功
```

### 6 大对话模式

#### 模式 1：均衡冲突
- 最常见：A 挑衅 → B 回应
- 适用：日常对话
- 反模式：所有场景都用（缺乏变化）

#### 模式 2：不对称冲突
- 强者少说，每句短而致命
- 适用：审讯、谈判、强者 vs 弱者
- 示例：
```
县令："姓名。"
"林修远。"
"所犯何事？"
"……"
"不答？来人，杖二十。"
```

#### 模式 3：非直接冲突
- 双方在说 A，其实聊的是 B
- 适用：情感戏、试探、暧昧
- 示例：
```
"今儿的月色真好。"（其实是：我想你）
"嗯，适合喝茶。"（其实是：我也在想你）
```

#### 模式 4：自反性冲突
- 角色与自己内心对话
- 适用：内心挣扎、道德困境
- 示例：
```
"我不能去。她是被冤枉的。"
"可去了又能怎样？死的只是你一个人。"
"……"
"不去，死的是她。"
```

#### 模式 5：微限冲突
- 用动作和留白代替台词
- 适用：情感高潮、关键转折
- 示例（不说一句话）：
```
他看了她一眼。
她低下了头。
他转身走出门。
她在门关上的一瞬，抬起手，又放下。
```

#### 模式 6：喜剧冲突
- 角色用错/反讽/玩笑表达真实意思
- 适用：搞笑向、轻松向
- 示例：
```
"你这么看着我做什么？"
"我只是在想，你这脸皮是天生的还是练的。"
"……你试试？"
```

## 2. 动作戏五公式

### 公式 1：动词颗粒度

**核心**：拆解"打"为精准动词

| 笼统 | 精准 |
|------|------|
| 打 | 砸/撞/轰/撕/劈 |
| 跑 | 冲/掠/闪/窜/跃 |
| 看 | 盯/扫/瞪/凝/窥 |
| 说 | 吼/喝/叱/叹/喟 |

**示例**：
- ❌ "他一拳打向敌人"
- ✅ "他攥拳，肘尖朝对方肋骨狠狠凿下去"

### 公式 2：力量感塑造

**核心**：受击者和环境反馈

```
不是写"打得多重"，而是写"承受的反馈"
```

**示例**：
- ❌ "他一拳打飞敌人"
- ✅ "他一拳砸在对方胸口。那人像被抽去了骨头，闷哼一声倒飞出去，撞断两根廊柱才停下，地面裂出蛛网般的纹路"

### 公式 3：五感画面感

**核心**：视听嗅触多通道

| 通道 | 示例 |
|------|------|
| 视觉 | 刀光一闪 / 鲜血溅在雪地上 |
| 听觉 | 骨裂声 / 剑鸣 / 惨叫声 |
| 嗅觉 | 血腥味 / 焦糊味 / 雷雨前的潮湿 |
| 触觉 | 虎口发麻 / 滚烫 / 冰冷 |
| 味觉 | 嘴角咸腥 / 舌尖苦涩 |

**反模式**：
- ❌ 全是视觉（"看见他冲来，看见剑光，看见血"）

### 公式 4：节奏控制

**核心**：蓄势长句→交火短句

```
蓄势：长句铺陈（环境/动作准备）
      ↓
交火：短句切碎（动作密集）
      ↓
余波：长句收尾（结果+余韵）
```

**示例**：
```
（长句蓄势）刀锋划破空气，激起一阵尖锐的啸声，
（短句交火）他侧身，躲。
  反手劈。
  对方举刀格挡。
  震开。
  追。
  砍。
（长句余波）那人踉跄后退，肩上多了一道口子，血顺着刀痕流下来，染红了半边衣襟。
```

### 公式 5：博弈感

**核心**：战术执行，信息差值

```
为什么这么打？利用了什么？对方为什么没躲过？
```

**示例**：
- ❌ "他一刀砍中敌人"
- ✅ "他看出对方左膝旧伤，故意引他左移，再突然劈右路。果然，对方躲不开——左膝一软，慢了半拍"

## 3. 感官描写（5 感并进）

### 5 感权重推荐

| 感觉 | 占比 | 适用 |
|------|------|------|
| 视觉 | 50-60% | 通用 |
| 听觉 | 15-20% | 动作戏/氛围 |
| 触觉 | 10-15% | 情感戏/动作戏 |
| 嗅觉 | 5-10% | 环境/回忆 |
| 味觉 | 5% | 食物/情感 |

### 感官锚点的"组合拳"

**单感官弱**："他很冷"
**多感官强**："他打了个寒战，手指冻得发僵，呼出的气在眉毛上结成了霜"

**5 感组合示例**：
```
（视觉）茶汤在青瓷杯中微漾
（听觉）远处有钟声传来
（嗅觉）茶香混着窗外桂花的甜
（触觉）杯壁微烫
（味觉）入口微苦，回甘悠长
```

### 感官描写 3 反模式

- ❌ 形容词堆砌（"美丽的花"）
- ❌ 通感滥用（"声音是红色的"——除非刻意）
- ❌ 静态描写（"这里的风景很美"）

## 4. 留白技法（升级项）

来自原 skill + 联网取经。

### 留白 vs 挖坑

| 留白 | 挖坑 |
|------|------|
| 读者能"猜到"作者没说的事 | 读者"完全不知道"作者在干嘛 |
| 情感张力 | 信息断层 |
| 高级技巧 | 写作缺陷 |

**检验**：留白是"读者知道但没说"，挖坑是"作者没给信息"。

### 留白 10 大手法

1. **动作留白**：写到关键动作，断章
   - "他抬起手——"
2. **对话留白**：对话不说完
   - "你……"她想说，又咽回去
3. **结果留白**：过程写了，结果不写
   - 他和那人说了几句，对方沉默良久，转身离去
4. **情感留白**：情感不直说，靠动作
   - 她没说话，只是把围巾给他系紧
5. **环境留白**：用环境暗示情感
   - 风停了。雪也停了。
6. **时间留白**：跳过一段时间
   - 三天后，他离开了
7. **视角留白**：换视角，前事不提
   - 从她的视角看，他那天很奇怪
8. **象征留白**：用象征物代替直说
   - 那盆兰花，终究还是枯了
9. **重复留白**：用重复表达复杂情感
   - "走吧。"他说。
   "走吧。"她也说。
10. **结尾留白**：用未说完的话结尾
    - 他想说"我……"
    风把他的话吹散了

### 留白的位置

- 章末（最常见）
- 关键动作前
- 情感高潮前
- 角色独白时

### 留白的 3 检验

- [ ] 读者能"补全"吗？（不能 = 挖坑）
- [ ] 留白后情感张力是否增强？（没有 = 失败）
- [ ] 是否与上下文呼应？（孤立 = 失败）

## 5. 主题锚定（升级项）

来自原 skill + 实践。

### 主题的层次

| 层次 | 表现 | 示例 |
|------|------|------|
| 显性主题 | 直接说 | "什么才是真正的强者？" |
| 隐性主题 | 通过故事暗示 | 通过主角的成长弧体现 |
| 母题词 | 反复出现的意象 | "剑"（勇气/孤独/守护） |
| 主题变奏 | 主题在配角身上的不同变体 | 师父追求"最强"，主角追求"问心" |

### 母题词设计

**3 次出现计划**：
- 第 1 次：建立意象
- 第 2 次：深化含义
- 第 3 次：象征性意义

**示例**（母题词："剑"）：
- 第 1 次：父亲留给他的剑（家族传承）
- 第 2 次：他用这把剑第一次杀人（权力的代价）
- 第 3 次：他把剑折断（放下执念）

### 主题锚定的方法

1. **第一句定调**（开场画面体现主题）
2. **关键抉择体现**（主角选择背后是主题）
3. **角色对照**（不同角色代表主题不同面）
4. **母题词复现**（贯穿全书的意象）
5. **结尾升华**（收场画面回归主题）

## 6. 伏笔设计（升级项）

### 伏笔的 5 类

| 类型 | 投放时机 | 回收时机 | 特征 |
|------|----------|----------|------|
| 物件伏笔 | 第 10 章 | 第 80 章 | 重要物品登场 |
| 人物伏笔 | 第 5 章 | 第 50 章 | 神秘人物首次出现 |
| 信息伏笔 | 第 20 章 | 第 30 章 | "你以后会知道" |
| 设定伏笔 | 第 1 章 | 第 200 章 | 世界观暗示 |
| 主题伏笔 | 开篇 | 结尾 | 贯穿全书 |

### 伏笔回收的 3 检验

- [ ] 回收时读者有"原来如此"的感觉？
- [ ] 与前文逻辑自洽？
- [ ] 没有"为回收而回收"？

### 伏笔密度

| 类型 | 密度 |
|------|------|
| 章级伏笔 | 每章 1-2 个 |
| 卷级伏笔 | 每卷 3-5 个 |
| 全书级伏笔 | 5-10 个 |

### 长线伏笔的"预埋"

**Chekhov 之枪原则**：如果第 1 章墙上挂着一把枪，第 100 章必须开枪。

**预埋技巧**：
- 看似不重要但细节清晰
- 给出可识别的标志（颜色/形状/声音/气味）
- 不要一次给太多信息（留待后文揭示）
- 与其他伏笔形成呼应

## 7. 写作文字五重境界

来自原 skill（保留）：

| 境界 | 表现 |
|------|------|
| 1 声音 | 叙事者有话说，不是摄像头 |
| 2 层次 | 情绪有起伏，不是单一色调 |
| 3 细节 | 动作具体化，画面感强 |
| 4 呼吸 | 长短句交替，张弛有度 |
| 5 活性 | 动词有力精准，删不必要的"的" |

> **第 4 重「呼吸」实操化（v2.2.1）**：长短句不是按规矩排的，是跟着"事情的密度"走的——密度高用短句追着写，密度低用长句铺陈。量化经验（对齐 human-writing check_prose）：
> - **句长变异系数 CV ≥ 0.42**：CV = 句长标准差 ÷ 句长均值。低于 0.42 像节拍器，没有呼吸；但也不是越大越好，关键是"该长则长、该短则短"，而非无序乱跳。
> - **禁连续短句鼓点**：连续 4 个以上 ≤6 字单句段，读起来像机关枪，是"急刹"病——拉开句长，让逗号续气、句号落点。
> - **禁段落等长鼓点**：一段一段都 80 字，节奏也是死的。长短段交替，呼吸才均匀。

## 8. 文字精炼（删字术）

### 删字 5 类

1. **删除"的"**
   - ❌ "他用力地握紧了拳头"
   - ✅ "他握紧拳头"

2. **删除副词"XX 地"**
   - ❌ "他缓缓地转过身"
   - ✅ "他转身"（缓不缓靠动作暗示）

3. **删除修饰语**
   - ❌ "他非常非常地生气"
   - ✅ "他攥紧了茶杯"

4. **删除冗余解释**
   - ❌ "他跑过去，因为他要去救她"
   - ✅ "他跑去救她"

5. **删除无信息量词**
   - ❌ "此时此刻，在那个地方"
   - ✅ "此刻"

## 9. 常见写作问题与解法

| 问题 | 症状 | 解法 |
|------|------|------|
| 流水账 | 无信息增量 | 每段至少 1 个新信息点 |
| 抽象心理 | "他感到很难过" | 外化为动作/环境（见 §11 心理描写专项） |
| 套路化 | 网文老梗堆砌 | 找新鲜角度 |
| 代词连续 | 连续"他/她"开头 | 变换主语 |
| 完整光滑对话 | 每句完整书面 | 加入打断/省略/答非所问 |
| 满篇"某某说" | 提示语癌，视觉疲劳 | 提示语替代四招（§1） |
| 角色声音雷同 | 遮名字分不清 | 4 清单 + 互换测试 |
| 动作戏单调 | 全是"打/踢/冲" | 动词颗粒度（5 公式） |
| 叙事密度失衡 | 一段塞太多 | narrative_density 控制 |

## 10. 写作时的实时自检

每写完 1000 字问自己：

1. 这 1000 字有 1 个新信息点吗？
2. 主角行为是从"心脏"长出来的吗？
3. 钩子（开头/内部/结尾）齐全吗？
4. 角色声音一致吗？
5. 有 AI 味吗？（破折号/因果句/感悟式结尾）

## 11. 心理描写专项（升级项）

> 来自成熟写作理论（show-don't-tell）的网文实操化收拢，是 §3 感官描写、§4 留白技法、第 05 人物心脏在「内心呈现」场景的交叉应用。本模块提供一站式可操作技法，而非新理论。

### 核心原则（与去 AI 味同源）

- **禁止**：贴标签式「他感到……」「她觉得……」+ 长篇内心独白水字数。这是 13_anti_ai「表达层」明确的 AI 味症状（P1 体验红线）。
- **主张**：不写心理，处处是心理——通过可观测信号（生理/动作/环境）让读者自己感受。
- **前提（铁律 7 差异化）**：所有心理描写必须从「人物心脏」（05 的欲望/恐惧/伤口）长出来。脱离心脏套招 = 套路化，反而同质化。

### 5 招技法

#### 招式 1：生理反馈法

- **核心**：人看不到别人的心，只能从反应推测。用身体反应替代情绪形容词。身体比大脑诚实。
- **反模式**：❌ 「他非常紧张。」
- **正例**：✅ 「他下意识在大腿上蹭了蹭手心的冷汗，喉结上下翻动，想咽口水，嗓子却像塞了把干冷的沙子。」（全程没提「紧张」，局促感扑面）
- **适用**：恐惧/愤怒/悲伤/紧张/羞耻等强情绪。常见映射：恐惧→瞳孔微缩、手心出汗；愤怒→指尖发颤；极悲→胃部痉挛。

#### 招式 2：感官情绪化（移情于景）

- **核心**：环境随角色情绪变色。用主角的眼睛过滤世界（限知视角）。
- **技巧**：感官扭曲法——心理压力极大时，安静的钟摆声像重锤砸心头；喧闹人群里他却觉得世界是死寂的灰。
- **反模式**：❌ 开心写「野花在对他笑」、害怕写「树叶像鬼哭」（廉价拟人）。
- **正例**：✅ 极度孤独：「他回家随手开了电视，不看，只想要屋里有个人声，哪怕是堆无聊的广告。」（用细节勾勒孤独，胜过喊 100 遍「我很孤独」）
- **适用**：情绪戏、氛围渲染。与 §3 感官组合拳结合。

#### 招式 3：心理卡位法

- **核心**：把心理拆碎，揉进动作/对话的「定格瞬间」，快准狠。网文里几百字内心独白 = 断阅读节奏 = 养书风险。
- **正例**：✅ 发现被信任的朋友背叛：「他举着酒杯的手定在半空，指甲因用力微微发白。盯着杯中晃动的液体，过了很久才轻声问：『什么时候开始的。』」（手定半空=卡位，指甲发白=卡位，轻声问=卡位）
- **适用**：反转、背叛、震惊。与 §4 留白（动作留白/情感留白）叠加，留白让读者补情绪。

#### 招式 4：言行落差法

- **核心**：极度悲伤/绝望时，人往往异乎寻常地平静，甚至笑。「我没事」越轻描淡写，读者越揪心。用表面反衬内心崩塌。
- **正例**：✅ 心里碎成玻璃渣，面对关心却淡淡笑一下：「我没事，挺好的。」
- **红线**：落差须有「心脏」支撑（他为何强撑？），否则是无病呻吟。
- **适用**：情感高潮、崩溃前夜。留白给读者，读者脑补的悲伤比直写深（经验性表述，未证实量化）。

#### 招式 5：逻辑链条 + 潜意识流

- **核心**：呈现主角脑内因果推演（观察→判断→联想→情绪爆发），读者跟着思维走 = 同步代入。
- **正例**：✅ 看见家门口陌生男鞋——①不是我的也不是妻的；②男鞋尺码大没干透→刚进来；③她说今晚加班，鞋却在这；④凉意夹怒意冲脑门。
- **潜意识流**：极度慌乱时思维不连贯，闪回荒诞细节（临死想到今早没叫妹妹吃早饭）——瞬间写活人。
- **适用**：悬疑/推理/高潮决策。
- **边界**：脑内推演 OK；对白泄密已知事 = 禁止（见 §1 对话军规 9 信息滴灌）。两招别混。

### 视角与类型标注（使用前提，避免一刀切）

- **第三人称限知（默认）**：5 招全适用，世界经主角眼睛过滤。
- **第一人称**：逻辑链条/潜意识流可更直给，但仍戒长篇独白。
- **类型差异**：爽文/悬疑重「逻辑链条 + 卡位」；言情/日常重「生理反馈 + 言行落差」；按书选调，勿全招硬塞。

### 与去 AI 味的衔接

- 「他感到…/她觉得…」是 13_anti_ai 表达层 AI 味症状 → 用本模块 5 招外化。
- 抽象心理一旦外化为生理/动作/环境，朱雀「感官锚点 ≥ 8/1000 字」等指标自然提升。

### 心理描写自检 5 问（写完一段内心戏问自己）

1. 这段有「贴标签」或「长篇独白」吗？（有 → P1，外化）
2. 情绪是否通过可观测信号（生理/动作/环境）呈现？
3. 这个反应是从该角色「心脏」长出来的吗？（换人做不出 = 失败）
4. 留白够吗？读者能自己补全情绪吗？
5. 逻辑链条/潜意识流是否服务主线，而非炫技？

### 一句话

心理描写不是「告诉读者他在想什么」，是「布置舞台灯光，让角色自己演，读者自己感受」。5 招是地基，不是模板——结合声音指纹（05）个性化，才是你的心理描写。

## 12. 文句呼吸与流畅度（治"加速急刹"节奏病）

> 来源：human-writing（活人感写作 v1.1.0）check_prose 的量化经验 + 网文实战。专治"车辆频繁加速与急刹"——句间节奏忽快忽慢、读着喘不上气或憋得慌。把 human-writing 的 5 条机制落地为网文可操作规则 **R1-R5**。

### R1 句式衔接：每句查前后承接

- **核心**：句子不是孤岛。前一句把"什么"交给后一句，后一句接住再往前走；长定语（3 个以上"的"）拆成小句，别堆成墙；主干（主谓宾）早点来，别让读者追到句尾才懂谁干了啥。
- **反模式**：❌ "那个穿着褪色蓝布长衫、手里攥着半张被雨水泡皱了的、三天前从镇上捎来的旧信的男人，终于在巷口停下了脚步。"
- **正例**：✅ "男人停在巷口。他穿着褪色蓝布长衫，手里攥着半张旧信——三天前从镇上捎来的，被雨水泡皱了。"

### R2 节奏呼吸：长短句跟事情密度走（治加速急刹）

- **核心**：密度高（冲突/动作/急转）→ 短句追着写；密度低（铺垫/回忆/环境）→ 长句铺陈。句长变异系数 CV ≥ 0.42；禁连续 4+ 个 ≤6 字单句段（机关枪鼓点）；禁段落等长鼓点。逗号续气、句号落点，别一逗到底也别满篇感叹号急刹。
- **加速急刹对照**：
  - ❌ 急刹型："他跑了。跑得很快。风很大。他摔倒了。很疼。他哭了。"（连续 5 个短句，像踩了 5 脚急刹）
  - ✅ 均匀呼吸型："他拼命往前跑，风灌进领口，凉得刺骨。脚下一滑，整个人摔在碎石路上，膝盖钻心地疼，眼泪不受控地涌出来。"（长句铺势 → 短句落点，张弛有度）

### R3 过渡衔接：每段接前段的问题

- **核心**：每段必须"新增东西 + 接前段抛出的问题"，不要另起炉灶。删掉"更深一层/话说回来/总而言之"这类路标词，让转折靠内容自然发生；场景（show）与概述（tell）交替，别整段概述或整段场景。
- **反模式**：❌ "上文讲完主角决心报仇。接下来，我们要更深入一层分析他的心理变化。"（路标词暴露结构，读者被拽出故事）
- **正例**：✅ 上段结尾"他攥紧了刀"。下段接："刀刃映出他自己的脸——那张脸，已经不像一个月前那个还会笑的人了。"（不解释，直接续）

### R4 口语还原：名词化翻回动词

- **核心**：AI 最爱写名词化长句（"进行了调整""完成了部署"），去掉动作感。翻回动词（"改了""布好了"）；连词密度控制在 7/千字以下（"因此/然而/而且"撑满句间 = 路标词过量）；单双音节按角色身份走（书生多用双音节文言，莽汉多用单音节短词）。
- **反模式**：❌ "他对当前的局势进行了审慎的评估，并就此作出了相应的部署。"（名词化 + 长定语，书面腔）
- **正例**：✅ "他打量了一圈，把人手分派下去。"（动词打头，利落）

### R5 断句呼吸：长前置提前主干

- **核心**：句首长状语/长定语（"在……之后""由于……"）超过 12 字，先把主干抛出来，再补修饰；动作已经把情绪写出来了，后面少解释一句（"他攥紧拳头，显露出愤怒"→ 删后半句）；一句一主干，避免一句话塞两个主语两件事。
- **反模式**：❌ "在经历了三天三夜不眠不休的围困并且眼看着粮草即将耗尽之后，守军终于决定打开城门投降。"（主干"守军投降"被压到句尾，喘不上气）
- **正例**：✅ "守军撑了三天三夜，粮草见底。终于，他们打开城门投降了。"（主干早来，断句给呼吸）

### 文句呼吸自检 5 问（写完一段问自己）

1. 句长有没有呼吸？（CV 够不够，还是有连续短句鼓点 / 段落等长鼓点）
2. 前一句把什么交给了后一句？接住了吗？
3. 有没有名词化长句可翻回动词？
4. 连词/路标词是不是过量（撑满句间）？
5. 长前置是不是压住了主干，断句给了呼吸吗？
