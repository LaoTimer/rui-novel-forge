# 世界观三招 + 经济体系（Worldbuilding）

> 网文 200 万字，80% 的世界观设定用不上。不要写万字，先用三招验真伪。

## 世界观的三层结构

| 层级 | 内容 | 占比 | 写入文件 |
|------|------|------|----------|
| **L1 核心** | 世界运转的根本逻辑（3 招） | 5% | `世界观.md` 顶部 |
| **L2 体系** | 力量/经济/势力/地理 | 20% | `世界观.md` 中部 |
| **L3 细节** | 文化/历史/风物 | 75% | 随写随补，不预先写 |

**铁律**：先想 L1，验完再写 L2，L3 边写边补。

**为什么**：网文平均寿命 200 万字，30 章后能用的核心设定不到 20%。**写万字世界观 = 浪费时间 + 自我限制**。

## 招式 1：资源分配与权力循环

**核心问题**：
- 这个世界最稀缺什么？
- 谁垄断了它？
- 普通人付出什么代价才能分到一点？

**为什么重要**：稀缺驱动欲望，欲望驱动冲突。没有稀缺 = 没有冲突 = 没有故事。

### 模板

```
稀缺资源 = [灵石 / 灵脉 / 寿命 / 知识 / 机遇 / 关系 / 信息 / 货币 / 权力]

垄断方 = [皇族 / 宗门 / 财阀 / 古老家族 / 神秘组织 / 神明]

普通人获取方式 = [卖身 / 投靠 / 出生 / 运气 / 投机 / 抢夺]

代价 = [生命 / 自由 / 尊严 / 家庭 / 寿命 / 灵魂]
```

### 示例（修仙世界）

```
稀缺资源 = 灵气
垄断方 = 各大宗门（按灵脉划分）
普通人获取方式 = 卖身给宗门当外门弟子 / 加入王朝当供奉
代价 = 自由（被宗门差遣）/ 寿命（灵气反噬）
```

### 示例（现代都市）

```
稀缺资源 = 资本 + 人脉 + 信息差
垄断方 = 财阀 + 高层圈子
普通人获取方式 = 卖身（996）/ 投靠（站队）/ 投机（赌博）
代价 = 时间 / 健康 / 家庭关系
```

### 示例（赛博朋克）

```
稀缺资源 = 数据 + 计算资源 + 神经接口
垄断方 = 巨型企业 + 黑客组织
普通人获取方式 = 卖数据 / 卖器官 / 黑入系统
代价 = 人性 / 自由意志 / 真实记忆
```

### 检验

- [ ] 主角能参与这个资源的分配吗？（不能 = 故事不成立）
- [ ] 反派能从这个资源中获取权力吗？（不能 = 反派不成立）
- [ ] 读者的现实经验能映射到这个世界吗？（不能 = 代入感差）

## 招式 2：链式反应

**核心问题**：
- 有了核心设定 X，经济/军事/文化/政治/社会/技术 会怎样变化？

**为什么重要**：链式反应是"世界运转"的来源。一个设定如果只是孤立存在，不能牵引整个世界变化 = 设定是死的。

### 模板

```
核心设定 = X
  ↓
X 让 [经济] 怎样了？
  ↓
X 让 [政治结构] 怎样了？
  ↓
X 让 [军事/武力] 怎样了？
  ↓
X 让 [文化/信仰/价值观] 怎样了？
  ↓
X 让 [日常生活/技术] 怎样了？
  ↓
X 的副产品/副作用是什么？
```

### 示例（灵气复苏）

```
核心设定 = 灵气复苏
  ↓
经济：灵石成为新货币，灵脉地产价格上涨
  ↓
政治：王朝失去对边境的控制，宗门崛起
  ↓
军事：普通人开始修炼，军队失去优势
  ↓
文化：修仙文化成为主流，学术地位下降
  ↓
日常：菜市场卖灵兽肉，地铁有灵兽专座
  ↓
副作用：灵气浓度不均导致新阶级固化，普通人被甩开
```

### 链式反应的 3 检验

- [ ] 至少影响 5 个领域？（经济/政治/军事/文化/日常）
- [ ] 有副作用或反作用？（不能全是好的，要有问题）
- [ ] 主角能利用或对抗这个链式反应？（必须有故事空间）

## 招式 3：文明共识

**核心问题**：
- 这个世界的人公认什么是对的？
- 哪些事是绝对不能做的？
- 哪些行为会被唾弃/惩罚？

**为什么重要**：文明共识决定人物行为的"潜意识"。一个修仙世界的修士不会随便滥杀无辜，因为"天道有眼"；一个赛博朋克世界的黑客不会轻易删除数据，因为"数据有价"。共识 = 行为边界 = 故事张力的来源。

### 模板

```
公认对的 = [努力就能成功 / 实力为尊 / 仁义为先 / 家族至上 / 知识就是力量]

公认错的 = [背叛师门 / 见死不救 / 欺师灭祖 / 欺软怕硬 / 卖友求荣]

绝对不能做 = [弑师 / 弑君 / 弑父 / 屠城 / 灭世]

灰色地带 = [复仇是否正义 / 撒谎是否道德 / 牺牲少数救多数]
```

### 示例（仙侠）

```
公认对的 = 实力为尊 / 师门情义 / 渡劫飞升
公认错的 = 背叛师门 / 魔修滥杀 / 欺师灭祖
绝对不能做 = 弑师 / 屠城 / 背叛天道
灰色地带 = 为救人杀人 / 为正义欺师 / 为苍生牺牲少数
```

### 文明共识的 4 大来源

1. **天道/神明/命运**（仙侠/玄幻/奇幻）— 违反会遭报应
2. **法律/制度**（都市/历史/科幻）— 违反会受惩罚
3. **江湖规矩/行规**（武侠/商战）— 违反会被同行唾弃
4. **道德/良知/人性**（现实/治愈）— 违反会内心不安

## 经济体系（升级项，本引擎新增）

**为什么必须单独列**：原 skill 没把经济当回事。但网文写到 30 万字以上，最常崩的就是"经济"——主角花的钱从哪来？反派怎么这么有钱？资源从哪来？

### 经济体系 4 问

1. **货币是什么**？（灵石/纸币/数字货币/以物易物/信用点）
2. **价值如何交换**？（市场/政府/黑市/期货/拍卖）
3. **资源从哪来到哪去**？（生产/分配/消费/回收）
4. **财富怎么集中和分散**？（积累/再分配/通胀/通缩）

### 示例（修仙）

```
货币 = 灵石（下品/中品/上品/极品，1:100 兑换率）
价值交换 = 坊市/拍卖行/以物易物（高阶物品）
资源流向 = 灵脉→宗门→弟子，民间通过任务/狩猎获得
财富集中 = 宗门寡头 + 顶级散修，民间贫富悬殊
```

### 示例（赛博朋克）

```
货币 = 数字信用点（绑定神经接口）
价值交换 = 数据黑市 + 巨型企业平台
资源流向 = 企业→数据中心→算法，个体通过卖数据获得
财富集中 = 巨型企业 + 黑客寡头
```

### 经济崩坏 4 大症状

- 主角突然有大量钱（无来源）
- 反派挥金如土（无成本控制）
- 物价混乱（前期一颗丹药值 100，后期值 1 万）
- 货币逻辑不一致（有时用灵石有时用银两）

**预防**：
- 建立"物价表"（持续更新）
- 重要支出必须有来源
- 重要收入必须有去处
- 货币逻辑不可混乱

## 势力博弈（升级项，本引擎新增）

**为什么重要**：网文到中段，主线推进 = 势力变化。如果势力是"画"的（设定里有但从不互动），故事就空。

### 势力设定 5 要素

```yaml
faction:
  name: 玄天宗
  power_level: 9          # 1-10 实力分级
  territory: 东域三国
  resources: 上品灵脉 ×3、灵石矿 ×1
  culture: 实力至上、师门情义
  allies: [青云派、白鹿书院]
  enemies: [血魔宗、暗影阁]
  leader: 掌门（实力 9、性格 严苛护短）
  internal_conflict: 派系之争（保守派 vs 改革派）
  current_goal: 抵御血魔宗入侵
```

### 势力博弈 3 规则

1. **势力必须有利益诉求**（不为了目标而存在的势力是纸老虎）
2. **势力之间必须有张力**（盟友/敌人/暧昧/竞争/合作）
3. **势力必须动态变化**（卷级势力图要变，不能从头到尾一张图）

### 势力图绘制（推荐）

每卷开始时画一张"势力关系图"：
- 中心：主角所在势力
- 第一圈：核心盟友/核心敌人
- 第二圈：次要关系
- 第三圈：潜在变数
- 标注：每条线的关系类型（盟友/敌人/暧昧/雇佣/从属）

**示例**：

```
        血魔宗（敌）
            ↕
        暗影阁（敌）
            ↓
  青龙帮（佣）──→ 主角 ──→ 玄天宗（盟）
            ↓
        青云派（盟）──→ 白鹿书院（友）
```

## 写作时的"世界观渗透"

**铁律**：世界观不能"讲解"出来，要"展示"出来。

### 5 种渗透手法

1. **对话中**（角色说"我家里有三亩灵田"——展示经济）
2. **动作中**（角色见到强者立刻下跪——展示等级）
3. **环境描写**（街道有灵兽车站——展示文化）
4. **内心独白**（"我堂堂先天境，怎么能输给他"——展示共识）
5. **剧情设计**（"他违反了师门规矩被追杀"——展示规则）

### 禁忌

- ❌ 长段设定说明（"这个世界有 8 大种族……"）
- ❌ 角色坐下来讲解设定
- ❌ 信息一次性倾倒
- ❌ 设定与故事无关

## 实战：30 分钟完成世界观骨架

### Step 1（5 分钟）：定 3 招

填写 3 招模板，得出：
- 稀缺资源
- 链式反应链
- 文明共识

### Step 2（10 分钟）：定经济体系

填写经济 4 问：
- 货币
- 交换
- 流向
- 集中与分散

### Step 3（10 分钟）：列 3-5 个核心势力

每个势力 5 要素：
- 名字/实力/领土/资源/文化
- 盟友/敌人/暧昧
- 当前目标
- 内部矛盾

### Step 4（5 分钟）：画势力图

画一张本卷势力关系图。

## 一句话总结

**世界观不是设定集，是"世界运转的逻辑"。** 三招验真伪，经济验可持续，势力验可互动。3 个检验过不去，再华丽的世界都是空中楼阁。
