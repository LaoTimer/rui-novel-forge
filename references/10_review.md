# 评审 + 中期体检 + 朱雀 + 声音一致性（Review）

> 评审不是"打分"，是"决策"。每个评审问题都要回答"修不修 + 怎么修 + 优先级"。

## 评审的 3 大场景

| 场景 | 时机 | 评审对象 | 输出 |
|------|------|---------|------|
| **章节评审** | 每章写完后 | 单章正文 | 6 角色评分 + 改进清单 |
| **中期体检** | 5/30/50/80 万字节点 | 整本书健康度 | 5 维度报告 + 续命建议 |
| **完结评审** | 全书写完后 | 整本书 | 总结 + 商业分析 |

## 场景 1：章节评审（6 角色 + 2 检测）

### 6 角色评审（升级自原 skill）

| 角色 | 关注点 | 权重 |
|------|-------|------|
| **阅读者** | 开篇吸引力、节奏、画面感 | 20% |
| **编审** | 错别字、病句、一致性 | 20% |
| **故事家** | 剧情逻辑、钩子、对话、弧光 | 20% |
| **文学顾问** | 语言艺术、人物刻画 | 15% |
| **毒舌读者** | 套路化、水文、毒点 | 10% |
| **AI 检测** | 朱雀+声音指纹一致性 | 15% |

**新增**：
- 读者画像匹配度（10%，从文学顾问中分出）
- 声音指纹一致性（5%，从 AI 检测中分出）

### 评分标准

| 分数 | 等级 | 处理 |
|------|------|------|
| 90-100 | 精品 | 可直接发 |
| 85-89 | 优秀 | 小改可发 |
| 75-84 | 良好 | 1-2 处修改 |
| 60-74 | 合格 | 多处修改 |
| 60 以下 | 不合格 | 重写 |

### AI 检测双指标

- **朱雀 AI 检测**：人工特征 ≥ 80% 通过
- **声音指纹一致性**：与锚点余弦相似度 ≥ 0.85

### 评审输出模板

写入 `评审/第XXX章.md`：

```markdown
# 第 50 章评审报告

## 综合评分
总分：86/100（优秀）

## 6 角色评分
- 阅读者：88 ✓
- 编审：92 ✓
- 故事家：85 ✓
- 文学顾问：89 ✓
- 毒舌读者：90 ✓
- AI 检测：82 ✓

## AI 检测双指标
- 朱雀：84%（≥80% ✓）
- 声音一致性：0.87（≥0.85 ✓）

## 改进清单
### P0（必须改）
- [无]

### P1（建议改，2 处以上必改）
- 第 3 段有抽象心理描写（"他感到很委屈"）→ 外化为动作
- 第 5 段对话略平，缺乏潜文本

### P2（攒 5 处批量润色）
- 句式重复（连续 3 段"他"开头）
- 形容词堆砌（"深沉的/复杂的/痛苦的"）

## 评审备注
本章节奏良好，钩子三段齐全，结尾"话说一半"有效。
建议下一步：第 51 章接住本章钩子，内部钩可设为"情感微时刻"做缓冲。
```

## 场景 2：中期体检（5 维度）

### 触发节点

| 节点 | 字数 | 重点 |
|------|------|------|
| 5 万字 | 首卷结尾 | 黄金三章+主角弧光+钩子密度 |
| 30 万字 | 第一波风险 | 战力+主线纯度+角色网 |
| 50 万字 | 第二波风险 | 换地图+副线价值+节奏曲线 |
| 80 万字 | 终局准备 | 收束+高潮+结局 |

### 5 维度体检

```yaml
health_check:
  trigger: "30 万字节点"
  date: "2026-08-11"

  # 1. 战力平衡
  power_balance:
    score: 78
    status: yellow
    issues:
      - "主角战力从筑基→金丹→元婴，30 万字涨了 3 个大境界"
      - "反派 BOSS 等级与主角差距未保持 ≥1 个大境界"
      - "敌人降智趋势：最近 10 章反派平均 3 章内败"
    recommendations:
      - "降低主角升境速度"
      - "强化反派维度（力量/道德/认知/魅力）"
      - "引入中期 BOSS（>1 个大境界的强敌）"

  # 2. 主线纯度
  plot_purity:
    score: 65
    status: red
    issues:
      - "核心目标推进度仅 40%"
      - "支线占比 35%（合理区间 20-25%）"
      - "主角从第 18 章起加入支线任务"
    recommendations:
      - "压缩支线或将支线转化为主线"
      - "回到核心目标：复仇/寻宝/拯救"
      - "明确未来 10 万字主线任务"

  # 3. 人物成长
  character_growth:
    score: 82
    status: green
    issues:
      - "主角弧光 8 章未变化（黄灯）"
      - "配角'柳如烟'5 章未出场（建议处理）"
    recommendations:
      - "下章设计主角关键选择（触发动机+恐惧）"
      - "设计柳如烟出场或明确她退场"

  # 4. 钩子密度
  hook_density:
    score: 90
    status: green
    issues:
      - "大钩子章占比 25%（合理 20-30%）"
      - "连续 5 章 ≥ 中等钩子（节奏偏快）"
    recommendations:
      - "第 31-32 章设计为缓冲章"

  # 5. 世界观一致性
  world_consistency:
    score: 88
    status: green
    issues:
      - "第 23 章'玄天宗'位置描述与第 8 章矛盾"
      - "未回收伏笔 5 个，最长 27 章未回收"
    recommendations:
      - "修正位置描述（统一为'东域'）"
      - "5 章内回收长线伏笔"

  # 综合
  overall: 80
  status: yellow
  alerts:
    - "主线纯度 65（红）：立即调整"
    - "战力平衡 78（黄）：建议调整"
    - "其他维度稳定"
```

### 体检状态解读

| 状态 | 分数 | 含义 | 行动 |
|------|------|------|------|
| green | ≥85 | 健康 | 继续 |
| yellow | 70-84 | 预警 | 关注 + 建议调整 |
| orange | 60-69 | 风险 | 必须调整 |
| red | <60 | 危险 | 立即停更调整 |

### 体检报告输出

写入 `体检/[字数]字体检报告.md`，包含：
1. 5 维度评分 + 状态
2. 具体问题清单
3. 改进建议
4. 处方（具体怎么做）

## 场景 3：完结评审

### 完结评审重点

1. **伏笔回收率**（应 100%）
2. **弧光闭环**（主角+核心配角）
3. **类型契合**（主类型纯度）
4. **节奏总览**（三态分布）
5. **商业数据**（追读/留存/完读率）

### 完结报告模板

```markdown
# 《XXX》完结评审

## 数据
- 总字数：___
- 总章节：___
- 完结日期：___
- 追读率走势：___
- 完读率：___

## 评审

### 故事完整性
- 伏笔回收：__/__
- 弧光闭环：✓/✗
- 结局合理性：✓/✗

### 类型表现
- 主类型纯度：__%
- 副类型配合：✓/✗

### 节奏总览
- 三态分布：压抑 30% / 爆发 50% / 余韵 20%
- 整体曲线：稳定上升

## 总结
[一句话总结这本书的得失]

## 经验沉淀
- 成功点：___
- 失败点：___
- 改进方向：___
```

## 评审的 3 大原则

1. **作者权威**：评审给建议，作者做决定
2. **不完美原则**：80 分就够发，不要追求 100
3. **节奏优先**：节奏问题比语言问题严重

## 评审常见问题

| 问题 | 症状 | 解法 |
|------|------|------|
| 评审过严 | 总在 60-70 分 | 调整评分标准 |
| 评审过松 | 总在 90+ | 加入毒舌读者权重 |
| 评审不客观 | 偏袒主角 | 6 角色 + 朱雀双盲 |
| 不会给建议 | 只说"不好" | 必须给"具体怎么改" |

## 与续命期的衔接

体检触发"red"或"orange"状态时，自动进入续命期（见 11_rescue.md）。

## 自动化脚本

```bash

# 输出：P0/P1/P2 清单 + 朱雀预估分

# 中期体检

```

## 一句话总结

**评审 = 体检 + 决策。** 不是写完打 100 分就完事，是回答"修不修、怎么修、什么优先级"。体检是 5 万字一做，章节是每章必做。两者结合 = 不会写崩。
