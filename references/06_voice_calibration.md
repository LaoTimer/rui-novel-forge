# 风格锚定 + 声音库（Voice Calibration）

> 在动笔前，先把"作者的声音"和"每个角色的声音"变成可机读的指纹。这是去 AI 味的最有效武器——不是写完再修，是写前就定调。

## 为什么需要"风格锚定"？

**原 skill 的问题**：等写完再去 AI 味，效率低 + 容易破坏节奏 + 治标不治本。

**本引擎的方案**：
1. 写前先定调（作者风格 + 角色声音）
2. 写时按锚点写（约束前置）
3. 写后做声音一致性校验（用余弦相似度）

**结果**：从源头减少 AI 味，而不是事后修补。

## 风格锚定的 3 个层次

| 层次 | 范围 | 何时建立 | 来源 |
|------|------|----------|------|
| **作者锚点** | 整本书的文风 | 阶段 3 启动 | 作者提供 3-5 个参考章节 |
| **类型锚点** | 同类作品的共性 | 阶段 3 启动 | 引擎自动分析同类 |
| **角色锚点** | 单个角色的语言 | 阶段 2（与人物卡一起） | 心脏 + 4 清单 |

## 作者风格锚点（Author Anchor）

### 步骤 1：收集锚点文本

作者提供 3-5 个"自己最满意"或"最喜欢别人写的"章节片段：

- 每个片段 300-500 字
- 来源：自己写过的、喜欢的网文、目标风格的范文
- 要求：能代表"想写的味道"

**示例**：
```
锚点 1：来自《剑来》第 12 章开头（烽火戏诸侯）
锚点 2：来自《赘婿》第 5 章（愤怒的香蕉）
锚点 3：作者自己写过的第 30 章片段
```

### 步骤 2：AI 提取 6 维特征

```yaml
author_anchor:
  # 1. 句长分布
  sentence_length:
    avg: 18 字
    distribution:
      short_3_8: 35%      # 短句占比
      medium_9_20: 45%    # 中句占比
      long_21_30: 15%     # 长句占比
      very_long_30_plus: 5%  # 超长句占比
    variation: 高（标准差 12）  # 句长变异度

  # 2. 词汇偏好
  vocabulary:
    high_freq: ["剑", "道", "悟", "问", "修", "本心", "不屈"]
    low_freq: ["啊", "呀", "嘛", "哒", "宝宝"]
    unique_words: ["我若不愿", "问心", "证道"]
    style: "古风+口语化"

  # 3. 节奏模式
  rhythm:
    dialogue_pace: 中快      # 对话节奏
    action_pace: 快          # 动作戏节奏
    description_density: 中  # 描写密度
    pacing_style: "短句切碎 + 长句蓄势"

  # 4. 感官锚点
  senses:
    visual: 60%              # 视觉占比
    auditory: 15%            # 听觉
    tactile: 15%             # 触觉
    olfactory: 5%            # 嗅觉
    gustatory: 5%            # 味觉
    multisensory_count: 8/1000字  # 多感官并用频率

  # 5. 对话特征
  dialogue:
    avg_length: 12 字
    style: "短句+省略+语气词"
    implied_meaning_ratio: 60%  # 潜文本占比
    pattern: "行动型对话为主"
    # 互换测试分数
    distinguishability: 0.85  # 1.0 满分

  # 6. 修辞习惯
  rhetoric:
    metaphor_freq: 中        # 比喻频率
    parallelism_freq: 低     # 排比频率
    repetition_freq: 低       # 重复频率
    unique_patterns: ["反问+短句断章", "环境呼应内心", "用典化用"]
```

### 步骤 3：生成作者锚点文档

写入 `声音/author_anchor.md`：

```markdown
# 作者风格锚点

## 6 维特征
[AI 提取的 6 维]

## 风格基线描述（一段话）
"本书风格以 [短句切碎+古风口语化] 为主，节奏 [快慢结合]，对话 [行动型]，
感官 [视觉为主+多感官点缀]，修辞 [反问+短句+用典]。
句长变异度高（标准差 12），阅读体验偏 [紧张/克制/爽脆]。"

## 写时约束
- 句长：短句 35%+ 中句 45%
- 词汇：避免"啊呀嘛哒宝宝"等口语
- 节奏：动作戏短句切碎，蓄势用长句
- 感官：每 1000 字至少 8 个多感官
- 对话：每句 ≤ 12 字，潜文本占 60%
- 修辞：反问和短句断章为招牌

## 写后校验
- 余弦相似度 ≥ 0.85
- 句长标准差 ≥ 10
- 互换测试 ≥ 0.8
```

## 角色声音指纹（Character Anchors）

来自 [05_characters.md §声音指纹](05_characters.md)，这里讲怎么生成和校验。

### 角色锚点文件

`声音/character_anchors/[角色名].yaml`：

```yaml
voice_anchor:
  name: 林修远
  source_text: |
    锚点 1："我若不愿，天地又能奈我何。"
    锚点 2："修道之人，问心而已。"
    锚点 3："本心若失，修道何用？"

  # 4 清单
  vocabulary_used: ...
  verbs: ...
  modifiers: ...
  forbidden_words: ...

  # 5 维特征
  sentence_length:
    avg: 14 字
    short_ratio: 50%
  dialogue_style: "短促/直白/不绕弯"
  catchphrase_freq: 高
  emotional_expression: "克制+行动化"
  distinguishability: 0.92

  # 写时约束
  constraints:
    - "对话平均 ≤ 14 字"
    - "每章至少 3 句招牌口头禅"
    - "禁用所有 forbidden_words"
    - "情绪不直说，靠动作暗示"
```

### 角色锚点的建立时机

**在阶段 2 架构期**（与人物卡一起）就要建立，不等动笔。

**为什么**：写正文前，必须知道"这个人会说什么话"。否则写到第 10 章角色突然换了声音。

## 类型锚点（Genre Anchor）

引擎自动分析同类作品，提取"这类小说的共性风格"。

### 步骤 1：选定 3-5 部同类代表作

如"古风权谋类"：
- 《剑来》
- 《赘婿》
- 《庆余年》
- 《雪中悍刀行》
- 《将夜》

### 步骤 2：AI 提取共性

```yaml
genre_anchor:
  type: 古风权谋
  shared_features:
    - "文言+白话混用，但偏白话"
    - "对话有'机锋'（话里有话）"
    - "动作戏有'意境'（不仅是打斗，是情绪）"
    - "环境描写有'画意'（画面感强）"
    - "节奏偏慢但张弛有度"

  differentiation:
    my_anchor_diff: "我比传统权谋多 30% 爽点节奏，但保留机锋对话"
```

### 类型锚点的功能

- 写时知道"这个类型通常这样写"
- 知道"我的差异化在哪里"
- 评审时知道"是否符合类型预期 + 是否有差异化"

## 风格锚定的实施

### 写时：5 约束前置

生成每章正文前，从锚点中提取 5 组约束，注入生成上下文：

```
约束 A：作者风格基线（句长/词汇/节奏/感官/修辞）
约束 B：作者禁忌（绝对不用的词/结构/修辞）
约束 C：本章出场角色声音指纹
约束 D：当前类型锚点（同类型共性）
约束 E：差异化角度（避免和别人撞）
```

### 写后：声音一致性校验

```bash
python scripts/voice_anchor.py check \
  --chapter 正文/第050章.txt \
  --author-anchor 声音/author_anchor.md \
  --character-anchors 声音/character_anchors/*.yaml
```

输出：
```
=== 第 50 章声音一致性报告 ===

作者风格相似度：0.87 ✓ (≥ 0.85)
句长变异度：11 ✓ (≥ 10)
感官密度：7/1000字 ⚠ (建议 ≥ 8)
潜文本占比：58% ✓ (≥ 55%)

角色声音一致性：
- 林修远：0.91 ✓
- 柳如烟：0.88 ✓
- 林修平：0.72 ⚠ (偏低，建议检查对话)

总体：✓ 通过
```

## 风格锚定 vs 反 AI 检测

| 维度 | 反 AI 检测（防御） | 风格锚定（建构） |
|------|-------------------|------------------|
| 思路 | 修掉 AI 痕迹 | 建立作者自己的声音 |
| 时机 | 写后 | 写前+写时+写后 |
| 工具 | 黑名单词/禁用结构 | 余弦相似度/特征向量 |
| 效果 | 暂时通过检测 | 长期作者性建构 |
| 上限 | 80% 人工特征 | 95%+ 作者辨识度 |

**两者结合**：风格锚定为主，反 AI 检测兜底。

## 实战：60 分钟完成风格锚定

### Step 1（20 分钟）：收集锚点文本

作者提供 3-5 个 300-500 字片段，AI 提取 6 维特征。

### Step 2（20 分钟）：建立角色锚点

每个核心角色 4 清单 + 5 维特征，写入 yaml。

### Step 3（10 分钟）：选定类型锚点

3-5 部同类代表作，AI 提取共性。

### Step 4（10 分钟）：写 3 章样章验证

写 3 章测试水，验证：
- 风格是否达到锚点
- 角色声音是否清晰
- 读者是否能 1 秒识别作者风格

如不达标，调整锚点或调整样章。

## 锚点调优循环

```
建立锚点 → 写样章 → 校验 → 偏差分析 → 调优锚点
       ↑                                        ↓
       └────────────────────────────────────────┘
```

**调优时机**：
- 每 10 万字回顾一次（看是否漂移）
- 风格变化时（如换地图/换卷）
- 读者反馈"风格变了"时

## 一句话总结

**风格锚定 = 给"作者性"装上 GPS。** 没有锚点，写到 50 万字自己都不知道风格漂到哪；有了锚点，每章都能校验"这还是不是我的风格"。这是长篇连载不写崩的核心保险。
