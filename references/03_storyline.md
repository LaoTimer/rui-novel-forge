# 故事线 3 层公式（Storyline）

> 故事线是故事的 DNA。在动笔前必须先有它。

## 故事线 vs 故事简介

| 类型 | 长度 | 功能 | 时机 |
|------|------|------|------|
| 故事线 | 1 句话 | DNA，定义故事本质 | 写正文前 |
| 一句话简介 | 50-100 字 | 营销，给读者看 | 写完主线后 |
| 故事大纲 | 数千字 | 施工图，章节规划 | 写前 + 持续更新 |
| 故事正文 | 数万字 | 最终产品 | 持续输出 |

**铁律**：故事线没定，不要开始写正文。否则写到 30 万字才发现 DNA 有问题，全书重写。

## 故事线 3 层公式（升级自原 skill）

```
L1 一句话冲突（故事的 DNA）
  = [主角] 想要 [原始欲望]，
    但被 [最大阻碍] 卡住，
    而 [转折/意外] 让一切变得不同

L2 情感承诺（读者合上书心里最重的那句话）
  = 一句话定调

L3 市场定位（在哪条赛道、和谁竞争、差异化在哪）
  = 1 段话说明
```

### L1 模板与示例

**模板 A（冲突型）**：
```
[主角身份] + [原始欲望] + [最大阻碍] + [转折/意外]
```

**示例 1**（重生创业）：
> "被合伙人坑破产的 35 岁销售，重生回 15 年前高考前夜，
> 带着未来 15 年的记忆，发誓这次不让悲剧重演，
> 但发现——重生的不止他一个。"

**示例 2**（玄幻）：
> "修为被废、跌落山崖的废材少爷，发现坠落处是万年封印的魔尊洞府，
> 魔尊没杀他，反而传他一身功法，要他替自己完成一件事——
> 杀了自己的亲传弟子。"

**示例 3**（言情）：
> "职场被性骚扰却投诉无门的女律师，
> 接到一桩看似普通的离婚案，对手律师是当年施暴者本人，
> 她必须在法庭上让对方败诉——同时不暴露自己也是受害者。"

**检验 L1**：
- [ ] 一句话能讲清楚吗？
- [ ] 主角的"原始欲望"是生存/被爱/复仇/自由/被认可这类基础欲望吗？
- [ ] 阻碍是具体的、可对抗的吗？
- [ ] 转折/意外是"有冲击力"的吗？
- [ ] 读者听完第一反应是"这个有意思"吗？

### L2 模板与示例

**模板**：
```
合上这本书，读者心里最重的那句话是："_____"
```

**选项**（来自《救猫咪》10 类型）：
- A."他太不容易了" → 麻烦家伙型
- B."他终于变了" → 成长仪式型
- C."爽！" → 傻瓜成功型
- D."这真相太震撼了" → 犯罪动机型
- E."这路走得太值了" → 金羊毛型
- F."吓得我睡不着" → 屋里有怪物型
- G."他俩太好了" → 伙伴之爱型
- H."这代价太大了" → 制度化型
- I."每个人选择都不一样" → 史诗型（反派视角）

**示例**：
- 《赘婿文》→ C 傻瓜成功型（"爽！"）
- 《凡人修仙传》→ E 金羊毛型（"这条路走得太值了"）
- 《诡秘之主》→ A 麻烦家伙型（"他太不容易了"）
- 《何以笙箫默》→ G 伙伴之爱型（"他俩太好了"）

**L2 一旦定，不可改**：它是所有分卷/副线决策的北极星。

### L3 模板与示例

**模板**：
```
[细分赛道] + [代表作品/竞争对手] + [我的差异化角度]
```

**示例**：
- 细分赛道：都市重生+年代创业
- 代表作品：《重生之大涅磐》《重生完美时代》
- 我的差异化：主角不是"开挂型"，而是"方法论型"，每步决策都有底层逻辑展示
- 避坑：不能写成无脑爽/不能写成后宫流/不能有系统

**L3 的功能**：在选平台、选读者画像、规划分卷时，作为定位锚。

## 故事线确认流程

```
Step 1：用户讲灵感（几句话）
        ↓
Step 2：AI 套 L1 模板生成 3 个候选
        ↓
Step 3：用户选 1 个或混搭
        ↓
Step 4：AI 套 L2 模板定情感承诺
        ↓
Step 5：AI 套 L3 模板定市场定位
        ↓
Step 6：反例边界（必填）
        ↓
Step 7：写入 设定/故事线.md
```

## 反例边界（必填，本引擎升级项）

每个故事必须有"反例边界"——明确说"这个故事不能写成 ___"，避免和别人撞+自我约束。

**示例 1**（玄幻）：
- ❌ 不能写成系统流（这本书没有系统）
- ❌ 不能写成后宫流（主角专一）
- ❌ 不能写成无敌流（必须有失败有挣扎）
- ❌ 不能写成"开局就巅峰"（必须有成长曲线）
- ❌ 不能让反派降智（必须旗鼓相当）

**示例 2**（言情）：
- ❌ 不能写成"傻白甜"（女主必须有脑子）
- ❌ 不能写成"出轨复仇"（这本书是治愈不是复仇）
- ❌ 不能写成"多角恋"（CP 单一）
- ❌ 不能让男主"霸总式控制"（要尊重女主意愿）

**示例 3**（现实题材）：
- ❌ 不能写成"行业百科"（故事是主体，行业是背景）
- ❌ 不能让主角"完美无缺"（要有真实瑕疵）
- ❌ 不能写成"金手指创业"（要靠真本事+资源积累）

**反例边界的来源**：
1. 看同赛道头部作品的"老梗"——这些必须避开
2. 自己的雷区——以前写过的、自己不喜欢的
3. 平台禁词——政治/低俗/价值观问题

## 主角选择 3 原则

故事线定下后，主角必须满足：

1. **能带来最大的冲突** — 主角的处境让冲突自然最大化
2. **情感上能走得最远** — 起点越低、终点越高，弧光越大
3. **能让最多的读者喜爱** — 被低估/被欺负/被抛弃/被束缚是跨题材共鸣点

**反例**：
- ❌ 选"全知全能"的反派（无法产生冲突）
- ❌ 选"完美开局"的富二代（弧光太短）
- ❌ 选"恶贯满盈"的恶人（无法让读者喜爱）

## 主角动机检验

主角的核心动机必须"最原始"——不需解释，听众"嗯我懂"。

**5 大原始动机**：
1. **生存** — 不被杀死/不被饿死
2. **被爱** — 被看见/被理解/被接纳
3. **保护** — 保护家人/爱人/孩子
4. **复仇** — 让仇人付出代价
5. **自由** — 不被束缚/不被控制

**检验问**：
- 这个动机需要超过一句话解释吗？→ 是 = 不够原始
- 读者听完有"嗯，我理解"的反应吗？→ 没有 = 重新想
- 角色到结局会"得到"这个吗？→ 不会（如果会满足，故事就结束了）

**注意**："得到了不会满足"是好动机的标志。
- 被爱 → 但永远在怀疑对方爱不爱自己
- 自由 → 但有了羁绊
- 复仇 → 但发现仇人也是受害者

## 故事线 vs 类型 DNA

故事线（what）≠ 类型（how）。

| 故事线 | 可以用不同类型表达 |
|--------|-------------------|
| "程序员被裁，重生创业" | 傻瓜成功型 / 麻烦家伙型 / 金羊毛型 |
| "离婚律师接案，对手是旧识" | 犯罪动机型 / 伙伴之爱型 / 成长仪式型 |
| "废材少爷发现魔尊传承" | 傻瓜成功型 / 屋里有怪物型 / 成长仪式型 |

**同一故事线，不同类型 = 完全不同的小说**。

**类型选择影响**：
- 主线情感承诺（L2）
- 15 节拍分布
- 角色弧光方向
- 卷级类型侧重
- 敌人类型（困难型 vs 强大型 vs 内在型）

详细见 [07_structure.md §类型体系](07_structure.md)。

## 故事线 vs 故事脊椎（Story Spine）

《救猫咪》提到"故事脊椎"——9 句话定故事节奏：

```
1. 一旦 [日常世界]
2. 有一天 [催化剂]
3. 鉴于此 [主角必须面对问题]
4. 结果 [主角尝试第一个办法]
5. 然后 [第一次失败]
6. 结果 [中点转折]
7. 然后 [第二次失败]
8. 然后 [灵魂暗夜]
9. 结果 [高潮决战 + 新日常]
```

**故事线（1 句）** + **故事脊椎（9 句）** = 故事结构基础。

## 实战：30 分钟完成故事线

### Step 1（5 分钟）：用 L1 模板填空

```
[主角身份] + [原始欲望] + [最大阻碍] + [转折/意外]
= _____ + _____ + _____ + _____
```

### Step 2（10 分钟）：用 L2 模板定情感承诺

```
合上书，读者心里最重的那句话是："_____"
= A/B/C/D/E/F/G/H/I 中的哪一类？
```

### Step 3（5 分钟）：用 L3 模板定市场定位

```
我在 [细分赛道]，和 [代表作品] 竞争，
我的差异化是 [反例边界 + 创新点]
```

### Step 4（10 分钟）：写下反例边界

列出 5-10 个"这个故事不能写成 ___"，作为自我约束。

### 输出

写入 `设定/故事线.md`：
```markdown
# 故事线

## L1 一句话冲突
[主角身份] + [原始欲望] + [最大阻碍] + [转折/意外]
= 完整一句话

## L2 情感承诺
合上书，读者心里最重的那句话是："_____"
类型：[类型名]

## L3 市场定位
细分赛道：
代表作品：
我的差异化：
- [反例边界 1]
- [反例边界 2]
- [反例边界 3]

## 主角动机
核心动机：生存/被爱/保护/复仇/自由
检验：[为什么这是最原始的]
深层矛盾：[这个动机"得到了也不会满足"的理由]
```

## 一句话总结

**故事线 3 层 = DNA + 北极星 + 定位。** 没有 L1 不要动笔，没有 L2 写到中段必崩，没有 L3 写完了没人看。3 层缺一不可。
