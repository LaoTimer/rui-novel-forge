# 商业期：数据 + 运营 + IP 孵化（Commercial）

> 网文是商品，不是艺术品。不懂数据 = 自嗨；不懂运营 = 写完没人看；不懂 IP = 浪费资源。

## 商业期的 3 大核心

1. **数据解读** — 看懂追读率/留存率/首秀/书测
2. **运营策略** — 选平台/选节奏/选断更预案
3. **IP 孵化** — 完结后怎么放大价值

## 1. 数据解读

### 5 大核心数据指标

| 指标 | 含义 | 健康线 |
|------|------|--------|
| 完读率 | 读完本书的读者比例 | 番茄 ≥ 30% / 起点 ≥ 50% |
| 追读率 | 继续追更的读者比例 | 番茄 ≥ 10% / 起点 ≥ 20% |
| 留存率 | 第 N 章还剩多少读者 | 10 章留存 ≥ 60% |
| 均订 | 起点订阅数 | 头部 ≥ 10 万 |
| 月票/打赏 | 平台数据 | 头部 ≥ 1 万 |

### 番茄数据细节

| 阶段 | 关键指标 | 警戒线 |
|------|---------|--------|
| 0-3 万字 | 收藏率 | < 5% 改文 |
| 3-8 万字 | 追读率 | < 10% 改节奏 |
| 8-15 万字 | 首秀数据 | 完读率 < 30% 调整 |
| 15-30 万字 | 持续追读 | 掉 30% 体检 |
| 30 万字后 | 长尾收益 | 完读率 < 20% 考虑完结 |

### 起点数据细节

| 阶段 | 关键指标 | 警戒线 |
|------|---------|--------|
| 0-5 万字 | 试读率 | < 5% 改文 |
| 5-15 万字 | 收藏+推荐票 | 增长缓慢改设定 |
| 15-20 万字 | 上架数据 | 首订 < 500 调整 |
| 20 万字后 | 月票榜 | 持续不进榜改节奏 |
| 100 万字后 | 长尾收益 | 看均订变化 |

### 数据跌的 4 大原因

| 原因 | 症状 | 对策 |
|------|------|------|
| 节奏变慢 | 完读率掉 | 加快节奏（每章必钩） |
| 设定冲突 | 评论区吐槽 | 修设定+加补丁 |
| 主角被动 | 评论区"太水" | 主角主动决策 |
| 套路重复 | 评论区"老梗" | 加新元素+揭悬念 |

## 2. 运营策略

### 平台选择（决策树）

```
你是新手？
├── 是 → 番茄（门槛低）或 知乎盐选（短篇）
└── 否
    ├── 写男性向 → 起点（IP 价值高）
    ├── 写女性向 → 晋江（口碑+改编）
    ├── 想稳定 → 七猫（保底）
    └── 短篇 → 知乎盐选

每平台特点详见 01_platforms.md
```

### 签约节奏

#### 番茄签约节点

| 字数 | 节点 | 操作 |
|------|------|------|
| 2 万 | 第 1 次签约申请 | 准备 5 书名+5 封面 |
| 5 万 | 第 2 次签约申请 | 如失败，调整节奏 |
| 8 万 | 第 3 次签约申请 | 最后机会 |

**注意**：番茄签约机会只有 3 次，3 次全败永久锁死。

#### 起点签约节点

| 字数 | 节点 | 操作 |
|------|------|------|
| 5 万 | 第 1 次审稿 | 编辑审稿 |
| 10 万 | 第 2 次审稿 | 决定是否能上推荐 |
| 15 万 | 上架申请 | 上架后开始订阅收益 |

#### 晋江签约节点

| 字数 | 节点 | 操作 |
|------|------|------|
| 3 万 | 第 1 次申请 | 准备 V 章 |
| 5 万 | 第 2 次申请 | 调整 |
| 10 万 | 第 3 次申请 | 上架 |

#### 知乎盐选

| 类型 | 操作 |
|------|------|
| 短篇 | 直接投稿 |
| 专栏 | 申请专栏作者 |
| 会员 | 自动进入会员池 |

### 番茄首秀策略

**关键节点**：
- 8 万字前不首秀（铺垫不够）
- 8-15 万字手动首秀（黄金期）
- 15 万字后系统强制首秀（被动）

**首秀前准备**：
- 5 书名+5 封面 A/B 测试
- 日更 4000+ 连续 3 天
- 关键钩子预埋（首秀前 3 章必有爆点）

**首秀期策略**：
- 日更 ≥ 4000 字
- 不要断更（断更 = 推荐流断崖）
- 连续 7 天首秀数据飘红

### 节奏预警

**什么时候该冲**：
- 首秀期（前 7 天）
- 大情节节点
- 平台活动期

**什么时候该缓**：
- 数据已稳
- 重大情节过渡
- 缓冲章（每 5-10 章 1 章）

### 断更预案

**断更的代价**：
- 推荐流断崖（直接降 30%）
- 追读率掉 20%
- 数据恢复需要 1-2 周

**必须断更的情况**：
- 重大健康问题
- 家人重大事件
- 不可抗力

**断更预案**：
1. 提前 3 天公告
2. 存稿保证断更期内仍能日更（哪怕少更）
3. 准备"回归爆点"（回归章必须有大钩子）
4. 主动向平台报备

**断更公告模板**：
```
作者[XXX]因[健康/家事/其他]原因，
将于[日期]起停更[X]天，
存稿[字数]已备，断更期内仍会保持[X 字/日]更新。
[日期]恢复正常更新，回归章准备了大爆点，敬请期待。
```

### A/B 测试

**测试什么**：
- 书名（5 个候选）
- 封面（5 个候选）
- 简介（2-3 个版本）

**测试时机**：
- 上线前（书名+封面）
- 首秀前
- 30 万字节点

**测试方法**：
- 番茄/七猫自带 A/B 测试
- 起点可在作品页换书名测试
- 看数据（哪个版本收藏率高）

## 3. IP 孵化

### IP 价值评估

| 维度 | 评分要素 |
|------|----------|
| 阅读数据 | 订阅/追读/完读率 |
| 口碑数据 | 评分/评论/书友圈 |
| 题材潜力 | 是否可改编（影视/游戏/动漫） |
| 完结度 | 完整故事（IP 改编需要完整） |
| 人物魅力 | 主角/配角是否立得住 |
| 世界观 | 是否可扩展（多季/系列） |

### IP 改编路径

#### 影视改编
- **门槛**：均订 ≥ 5 万 + 口碑评分 ≥ 8.5 + 题材热门
- **流程**：作者授权→制片方购买→剧本改编→拍摄→上线
- **周期**：2-3 年
- **收益**：版权费（百万级）+ 后续分成

#### 动漫改编
- **门槛**：均订 ≥ 3 万 + 题材适合（玄幻/科幻优先）
- **流程**：动画公司购买→制作→上线
- **周期**：1-2 年
- **收益**：版权费 + 周边分成

#### 游戏改编
- **门槛**：均订 ≥ 5 万 + 世界观完整
- **流程**：游戏公司购买→开发→上线
- **周期**：2-4 年
- **收益**：版权费（千万级）+ 流水分成

#### 有声改编
- **门槛**：低（订阅过万即可）
- **流程**：平台制作→上线
- **周期**：3-6 月
- **收益**：制作费（几万）+ 流水分成

#### 实体出版
- **门槛**：高（均订 ≥ 10 万）
- **流程**：出版社购买→编辑→印刷→发行
- **周期**：1 年
- **收益**：版税（5-10%）

#### 海外传播
- **门槛**：题材合适（仙侠/玄幻/系统流）
- **平台**：Webnovel（起点海外）/ Wuxiaworld
- **流程**：翻译→海外平台上线
- **周期**：1-3 月（AI 翻译加速）
- **收益**：海外订阅分成

### IP 孵化的关键

1. **完结** — 90% 完结作品比 30% 太监作品 IP 价值高 10 倍
2. **完整性** — 故事完整可改编
3. **延展性** — 主角成长线清晰，多季可能
4. **人物魅力** — 角色能被记住（IP 核心是"人"）
5. **世界观** — 可扩展（多地图/多角色/多势力）

## 4. 完结运营

### 完结前的 3 个月

- 提前规划结局（不要突然完结）
- 写"完结感"（不要戛然而止）
- 准备完结番外（1-3 章）
- 写"完结感言"（建立情感连接）

### 完结后 1 个月

- 完结奖（部分平台有）
- 长尾订阅收益
- 准备新书（不要断更太久）

### 完结后长期

- 老书推荐（读者转化）
- IP 改编接触
- 维护书友圈
- 完结活动参与

## 5. 多平台运营

### 可同步的平台

| 组合 | 内容差异 | 操作 |
|------|---------|------|
| 番茄+七猫 | 小 | 可同步 |
| 起点+番茄 | 中 | 节奏调整后同步 |
| 起点+晋江 | 大 | 不同内容 |

### 同步的代价

- 节奏难两全
- 更新压力大
- 数据归因困难

### 建议

**主攻 1 个平台 + 1-2 个次要平台**

```
主攻：番茄（高流量 + 广告变现）
次要：七猫（保底）
不投：起点（节奏不同）
```

| 时间点 | 必做 | 警戒 |
|--------|------|------|
| 0-1 万字 | 平台选型+读者画像 | 题材不匹配 |
| 1-3 万字 | 黄金三章打磨 | 试读率 < 5% |
| 3-8 万字 | 节奏控制 | 追读率 < 10% |
| 8-15 万字 | 签约+首秀准备 | 3 次签约失败 |

| 30-50 万字 | 中期体检 | 体检 red/orange |

| 80-100 万字 | 完结铺垫 | 烂尾 |
| 完结 | 完结运营 | 完结不运营 |

- ❌ 政治敏感

## 8. AI 工具的合规使用（2026 新规）

### 番茄 AI 政策
- 纯 AI 生成：永久封禁
- AI 辅助：需提交人工底稿
- 原创度必须 100%

### 起点 AI 政策
- 需声明 AI 使用情况
- AI 辅助创作允许，全 AI 禁止
- 编辑会抽查

### 通用原则
- AI 是工具，不是作者
- 必须有"作者性"
- 关键章节必须人工

## 9. 商业期的常见误区

| 误区 | 后果 | 正确做法 |
|------|------|----------|
| 自嗨不分析数据 | 数据掉不知道 | 每周看数据 |
| 盲目跟风 | 失去差异化 | 差异化优先 |
| 一味求快 | 烂尾 | 质量优先 |
| 断更不预告 | 推荐流断崖 | 必须预告 |
| 多平台同步 | 节奏乱 | 主攻 1 个 |
| 不存稿 | 断更 | 存稿 3 万+ |
| 忽视评论区 | 错过反馈 | 每周看评论 |
| 完结就放 | 浪费 IP | 完结运营 |

## 一句话总结

**商业期 = 数据 + 运营 + IP。** 三者缺一不可。数据告诉你"读者在不在"，运营决定"读者来不来"，IP 决定"未来值多少"。商业思维不是"低俗"，是"对读者负责"。
