# 5 分钟快速上手（Quickstart）

> 拿到引擎不知道从哪开始？看完这页就能开书。

## 三步启动

### Step 1：项目启动（10 分钟）

回答三个问题，引擎自动生成 `project_state.yaml`：

1. **平台**：番茄 / 起点 / 晋江 / 七猫 / 知乎盐选 / 其他
2. **读者画像**：年龄/性别/场景/共情点（一句话即可）
3. **目标**：百万字 / 中篇 / 短篇 + 日更字数

**AI 会**：
- 查平台最新政策（签约节点/收益模型/算法逻辑）
- 算收益模型（按目标字数+日更+追读率预估月入）
- 匹配同类作品（找差异化空间）

**你要做的**：
- 选定平台（钱是你赚，听你的）
- 写一段 200 字"为什么写这本书"（私密的，引擎不外传）

### Step 2：种子期（30 分钟-2 小时）

把灵感变成"一句话能讲清楚的故事"。

**3 层故事线公式**：
```
L1 一句话冲突：    [主角] 想要 [原始欲望]，但被 [最大阻碍] 卡住
L2 情感承诺：    合上书，读者心里最重的那句话是
L3 市场定位：    什么赛道 + 和谁竞争 + 我的差异化是
```

**反例边界**（必填）：
- "我这个故事不能写成 ___"（避免和别人撞）
- 例：不能写成废柴流（要靠真本事）/不能写成后宫流（单一女主）/不能写成升级流（要靠人情练达）

**输出**：
- `设定/故事线.md`
- `设定/反例边界.md`

### Step 3：架构期（1-3 天）

搭骨架——世界观、人物、故事、分卷。

**优先级**：
1. **人物心脏**（先做，比世界观重要）— 主角 10 问 + 声音指纹
2. **世界观三招**（资源/链式/共识）+ 经济体系
3. **故事骨架**（四层瀑布：种子→编排→架构→叙事→渲染）
4. **分卷规划**（6-8 卷，每卷节拍 + 类型侧重）
5. **3 章样章**（试水，验证风格+开局）

**不要**：
- 不要先写万字世界观（30 章后用不上 80%）
- 不要先列 100 个角色（核心 5-8 个就够）
- 不要写超过 10 章才回头看（边写边体检）

## 红线速查

| 级别 | 一句话定义 | 处理 |
|------|-----------|------|
| **P-1** | 商业红线 | 立即停更。例：全 AI 代写/政治敏感/抄袭/不预告断更 |
| **P0** | 质量红线 | 当章必须改。例：人物 OOC/前后矛盾/价值观崩坏 |
| **P1** | 体验红线 | 累积 2 处必须改。例：AI 味/对话无行动/钩子缺失 |
| **P2** | 优化红线 | 攒 5 处做一次批量润色。例：句式重复/感官锚点少 |

## 触发引擎的常用话术

| 你说 | 引擎进入 |
|------|----------|
| "开新书" / "我想写本小说" | 0.项目启动 |
| "我的灵感是…" / "帮我提炼故事线" | 1.种子期 |
| "帮我设计世界观/人物/大纲" | 2.架构期 |
| "校准文风" / "提取我的风格" | 3.风格锚定期 |
| "写第X章" / "推进N章" | 4.创作期 |
| "评审这章" / "这章怎么样" | 5.评审期 |
| "写到X万字" / "感觉不对劲" | 6.体检期 |
| "剧情崩了" / "救救我" | 7.续命期 |
| "追读率掉了" / "数据不好" | 8.商业期 |
| "我卡了" / "没灵感" / "想放弃" | 10.作者工坊 |
| "项目状态" / "看看进度" | 11.项目仪表盘 |

## 卡壳急救（第一次用本引擎时）

| 你的状态 | 推荐先做 |
|----------|----------|
| 完全没灵感 | 从作者工坊的"灵感激活器"开始，5 类来源先试 1 类 |
| 灵感模糊 | 直接进 1.种子期，3 层公式填空 |
| 灵感清晰但不敢动笔 | 先做 3.风格锚定（拿你喜欢的网文章节喂给引擎） |
| 写了几万字但卡住 | 进 6.体检期 + 7.续命期 |
| 第一次写网文 | 先看 12.商业期 §新手避坑 |

## 一句话总结

**作者是主理人，AI 是工具。** 不要让 AI 替你决定任何事——灵感、人物心脏、关键反转、招牌章节，必须是"你的"。AI 帮你的是效率、整理、机械检测、选项生成。掌握这条边界，你就掌握了本引擎。
