# 创意多样性引擎（Creative Diversity）

> 公式给你"正确"，多样性给你"意外"。网文最怕的不是写错，是"正确但无聊"。
> 本文件解决一个具体问题：**同一个设定，你能写出几个不一样的版本？**

## 它解决什么痛点

| 痛点 | 表现 | 本文件给的武器 |
|------|------|----------------|
| 情节套路化 | 每个高潮都"扮猪吃虎+打脸" | 情节变体生成法 |
| 角色脸谱化 | 反派都是"哈哈哈小辈" | 角色反套路 + 混搭矩阵 |
| 对白千篇一律 | 所有角色说话一个味 | 对白多解 + 潜台词三层 |
| 卡在"还能怎么写" | 想不出第 2 条路 | 旋转门法 + 约束生成 |
| 为不同而不同 | 创新变成炫技 | 变体质量自检 |

**铁律**：变体不是目的，差异化也不是目的。**好读 + 和心脏有关 + 和别人不同**，三者缺一不可（见 §6 收敛）。

## 1. 情节变体生成法（Plot Variation）

核心思路：同一个"场景骨架"，换不同的"进入方式"和"代价"，就能长出完全不同的情节。

### 1.1 旋转门法（同一个房间，不同的门）

固定"场景目的"不变，只换"角色怎么进这个场景、带什么代价"。

```
固定：第 30 章必须是"主角与师父决裂"
变体门：
  门 A（误会门）：师父隐瞒了主角身世 → 主角觉得被背叛
  门 B（理念门）：师父要牺牲百姓换大局，主角不肯 → 主动决裂
  门 C（时间门）：主角看见未来师父会害他 → 先下手为强
  门 D（替身门）：被陷害的人不是师父而是孪生兄弟 → 错怪
  门 E（沉默门）：师父已死，决裂发生在墓前独白
```

**用法**：列出场景目的 → 强制写 5 个不同"门" → 收敛选 1。

### 1.2 五角度变体矩阵

对任一关键情节，从 5 个角度各生成一个变体：

| 角度 | 问题 | 变体方向 |
|------|------|----------|
| 视角 | 谁在讲述？ | 主视角 / 反派视角 / 旁观者 / 物件视角 |
| 动机 | 为什么做？ | 利他 / 利己 / 被胁迫 / 误判 / 偶然 |
| 时序 | 什么时候发生？ | 提前 / 延后 / 倒叙揭晓 / 并行发生 |
| 胜负 | 谁赢？ | 主角惨胜 / 主角惨败 / 两败 / 第三方捡漏 |
| 代价 | 付出什么？ | 血肉 / 关系 / 信念 / 时间 / 秘密 |

**示例**（"主角拿到秘籍"）：
- 视角变体：从秘籍前任主人的亡魂视角讲这段
- 动机变体：主角拿秘籍不是为变强，是为毁掉它
- 代价变体：拿到秘籍的代价是忘掉一个人

### 1.3 约束生成（逼出非套路）

给生成器 3 个硬性约束，强制跳出舒适区：

```
约束示例：
  ① 这一章不准出现任何打斗
  ② 反派必须说真话
  ③ 事件必须发生在主角最虚弱的时刻
```

**原理**：没有约束，AI 和作者都会掉进"最省力的套路"。约束是创造力的催化剂。

### 1.4 反结局法

列出 5 个俗套结局，强制写第 6 个：

```
俗套（禁用）：
  1. 主角登顶无敌
  2. 反派洗白当朋友
  3. 全员圆满大团圆
  4. 主角牺牲感化敌人
  5. 突然觉醒系统是外星人
第 6 个（真正写）：
  → 主角赢了但失去复仇的意义，把剑插回师父墓前
```

### 1.5 故事脊椎变体

《救猫咪》9 句脊椎，每句给 3 种走法（来自 references/03_storyline.md）：

```
第 4 句"主角尝试第一个办法"：
  A. 主动出击（主角性格使然）
  B. 被迫应战（环境所迫）
  C. 误打误撞（意外推动）
```

## 2. 角色反套路生成法（Character Anti-trope）

### 2.1 七种反套路面具

把"常见标签"翻转，得到有反差的人：

| 面具 | 表面 | 里子 | 反转钩 |
|------|------|------|--------|
| 温柔的暴君 | 温言软语 | 掌控欲极强 | 他为你好，所以你不能有选择 |
| 聪明的弱者 | 不懂武功 | 算无遗策 | 他赢在让所有人低估他 |
| 忠诚的叛徒 | 誓死跟随 | 另有所图 | 他的忠诚另有对象 |
| 天真的操控者 | 单纯无害 | 玩弄人心 | 他真信自己没错 |
| 懦弱的英雄 | 遇事就躲 | 关键时刻顶上 | 他怕，但他去 |
| 话痨的杀手 | 不停说话 | 句句是杀招 | 话越多越危险 |
| 诚实的骗子 | 从不撒谎 | 只说一半 | 真话也能骗死人 |

**用法**：选一个面具 → 套进"心脏 10 问"（references/05_characters.md）→ 长出非脸谱的角色。

### 2.2 混搭矩阵（A 的欲望 + B 的恐惧 + C 的伤口）

```
随机组合 3 个来源，撞出新角色：
  欲望池：被爱 / 自由 / 复仇 / 保护 / 被认可
  恐惧池：暴露脆弱 / 变成恶人 / 再次失去 / 被遗忘
  伤口池：被背叛 / 被抛弃 / 亲手害死人 / 永远第二

例：欲望=被认可 + 恐惧=变成恶人 + 伤口=永远第二
  → 一个拼命想被认可、却最怕自己手段越来越像反派、因为从小活在被比较阴影里的人
```

### 2.3 反差三明治

```
表层（读者第一眼看到）：高冷剑客
夹心（相处后看到）：怕黑，每晚点灯
底层（关键时刻暴露）：怕黑是因为小时候全家死在黑暗里
```

**检验**：三层的反差越大、逻辑越自洽，角色越难忘。

### 2.4 从"功能"反推角色

先定这个角色必须完成的**叙事功能**，再长成具体的人：

```
功能：必须在第 40 章"出卖主角"
反推：
  - 不能是天生的坏 → 给他"被胁迫的家人"
  - 不能毫无铺垫 → 前面埋"他总在深夜出门"
  - 不能让读者恨死 → 出卖后他救了主角的妹妹
```

## 3. 对白多解生成法（Dialogue Multi-solution）

### 3.1 同一冲突的 5 种开场

```
冲突内核：A 发现 B 瞒了他一件事
  开场 1（挑衅）："你什么时候学会骗我了？"
  开场 2（示弱）："你是不是……不信任我了？"
  开场 3（沉默）：A 看着 B，没说话，把茶杯放下。
  开场 4（玩笑）："行啊，藏得挺深，差点没让我笑场。"
  开场 5（错位）："今天天气真好。"（其实在说那件事）
```

### 3.2 同一种情绪的 5 种表达

```
情绪：愤怒
  1. 爆裂："你疯了！"
  2. 冰封："……我听明白了。"
  3. 动作：他把碗摔在地上，碎片溅了一地。
  4. 迂回："你做得真漂亮。"
  5. 自嘲："我生什么气呢，我又不是第一次被你骗。"
```

### 3.3 潜台词三层（说出的 / 暗示的 / 真正想的）

```
说出："你走吧，我不留你。"
暗示：我希望你别走。
真正想：我留不住你，但我爱你。
```

## 4. 设定/世界观多样性

### 4.1 资源稀缺的 10 种非货币形态

不只有"钱"。稀缺什么，决定世界运转方式：

```
1. 时间（寿命可交易）
2. 记忆（健忘是病）
3. 信任（被背叛过的人稀缺）
4. 命名权（无名者不存在）
5. 影子（没影子的人被驱逐）
6. 梦境（睡着会死）
7. 声音（哑巴是贵族）
8. 死亡（死不了是诅咒）
9. 真相（说谎者才自由）
10. 选择（命运已被写定）
```

### 4.2 链式反应"蝴蝶翅膀"

```
核心设定：这个世界的雨是咸的
  → 土壤盐碱化 → 庄稼难活 → 粮食是硬通货
  → 沿海人迁徙内陆 → 内陆冲突加剧
  → 诞生"储水教" → 宗教战争
```

**用法**：定 1 个反常设定 → 推 3 层连锁后果 → 世界自己活起来。

## 5. 创意发散-收敛工作流（Diverge-Converge）

### 发散阶段（禁止自我审查）

```
Step 1：固定"不能变"的（心脏 / 类型 DNA / 反例边界）
Step 2：强制生成 10 个版本（情节/角色/对白都行）
Step 3：不准删，全写下来
Step 4：如果第 10 个和第 1 个一样 → 再加 5 个约束逼自己
```

### 收敛阶段（3 问筛选）

```
问 1：读者会买账吗？（追读动力）
问 2：和主角心脏有关吗？（不是为炫技）
问 3：和别人不同吗？（差异化）
→ 3 问全过 = 采用；过 2 = 备选；过 1 或 0 = 丢弃
```

## 6. 与引擎集成（在哪调用）

| 阶段 | 调用本文件的哪部分 |
|------|--------------------|
| 1 种子期 | 故事线本来就有 3 候选，本文件把"3 候选"升级成"N 变体"（§1.5 脊椎变体） |
| 2 架构期 | 反套路角色（§2）+ 世界观多样性（§4） |
| 4 创作期 | 对白多解（§3）+ 情节变体（§1）卡壳时随时调用 |
| 10 作者工坊 | 卡文时强制套"旋转门法"或"约束生成"破局 |

**配合声音指纹**：所有变体必须用角色 4 清单（references/05_characters.md）筛选，确保"多样但不 OOC"。

## 7. 变体质量自检（避免为不同而不同）

- [ ] 变体是否服务于"心脏"？（不是作者炫技）
- [ ] 变体是否读者可感？（太隐晦 = 白写）
- [ ] 变体是否和前文自洽？（不破坏世界观）
- [ ] 变体是否真的"不同"？（不是换汤不换药）
- [ ] 变体是否可收束？（后面能圆回来）

## 实战：15 分钟生成一个"不一样的高潮"

### Step 1（3 分钟）：固定不可变量
写出本章"必须发生的事" + 主角心脏。

### Step 2（7 分钟）：旋转门法
强制 5 个"门"，每个 1 句话。

### Step 3（3 分钟）：约束生成
加 2 个反套路约束（如"不准打斗""反派说真话"）。

### Step 4（2 分钟）：3 问收敛
选 1 个通过的。

## 一句话总结

**套路是地基，多样性是楼层的样子。** 没有地基（公式/心脏/类型），多样性是空中楼阁；只有地基没有多样性，书就是千篇一律的复制品。本文件让你在"正确"的地基上，长出"意外"的楼。
