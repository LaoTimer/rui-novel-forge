# 人物心脏 + 声音指纹 + 弧光（Characters）

> 简历描述一个人，心脏驱动一个人。声音指纹让一个人开口就能被认出。弧光让一个人活过整本书。

## 三个层次的关系

```
人物小传
├── L1 简历层（外在）— 身份/外貌/职业/履历
├── L2 心脏层（内在）— 欲望/恐惧/伤口/矛盾
└── L3 声音层（表达）— 词汇库/句式/行为模式/专属
```

**铁律**：
- 没 L1 = 工具人
- 没 L2 = 主角写着写着就成神
- 没 L3 = 千人一腔（AI 味重灾区）

## L1 简历层（必备，速写）

每个核心角色必须有的基础信息：

```yaml
character:
  name: 林修远
  age: 28
  gender: 男
  identity: 前修仙天才，现废材少爷
  appearance: 中等身材，眉头有旧伤疤，眼神略带忧郁
  occupation: 家族庶出弟子 → 流放 → 复仇者
  background: 三年前被堂兄陷害，修为被废，家族除名
  social_status: 曾经核心弟子，现在边缘人
```

**L1 是骨架**——不需要写得多华丽，能让作者"想象出这个人"就行。

## L2 心脏层（人物小传心脏法 10 问）

来自升级版——比原 skill 多了"声音指纹"+"专属伤口"两个层次的强调。

### 10 问结构

| 层次 | 问题 | 核心 |
|------|------|------|
| **核心欲望** | ①他口头上想要什么？<br>②真正驱动他的是什么？<br>③得到了会满足吗？ | 总驱动力 |
| **核心恐惧** | ④最怕暴露哪一面？<br>⑤什么处境会触发逃跑/反击？<br>⑥最怕变成谁？ | 过度反应的金矿 |
| **未愈合的伤口** | ⑦哪个时刻让他从此不一样？<br>⑧留下了什么具体行为习惯？ | 弧光支点 |
| **内在矛盾** | ⑨有什么连自己都说不清的自相矛盾？<br>⑩何时会做出自己也意外的事？ | 真实感+成长空间 |

### 10 问速答模板

**示例 1（主角林修远）**：
```
① 表面想要：重回家族，夺回一切
② 真正想要：证明自己不是废物
③ 得到了会满足吗？不会。他真正怕的是"再次失去"

④ 最怕暴露：内心的脆弱和自卑
⑤ 触发逃跑/反击的处境：被当众羞辱 → 反击；被亲人否定 → 逃跑
⑥ 最怕变成谁：像堂兄那样心狠手辣

⑦ 改变他的时刻：被废修为那夜，师父为他挡了一剑而死
⑧ 行为残骸：紧张时摸眉头的疤；信任一个人时会下意识后退半步

⑨ 自相矛盾：嘴上说"我不信任何人"，但总在关键时刻救弱者
⑩ 意外的瞬间：师父死时他没有哭，但后来在没人时哭了一整夜
```

### 10 问的两种使用模式

**模式 A：交互式**（推荐新手）
- AI 逐问引导，作者逐个回答
- 10 问答完自动生成人物卡

**模式 B：一次性**
- 作者直接写"这是主角的心脏：……"
- AI 解析并生成人物卡

### 10 问优先级

| 角色类型 | 必答 | 选答 |
|----------|------|------|
| 主角 | 全部 10 问 | — |
| 核心反派 | 全部 10 问 | — |
| 重要配角 | ①②④⑤⑦⑧ | ③⑥⑨⑩ |
| 功能型配角 | ①④ | ②⑤⑦⑧ |

## 声音指纹（Voice Fingerprint）— 本引擎升级项

**为什么单独列**：原 skill 只有"对话不要雷同"，但没给出"怎么让对话不雷同"的方法。本引擎引入"声音指纹 4 清单"，让每个角色有可机读的"语言身份证"。

### 声音指纹 4 清单

```yaml
voice_fingerprint:
  character: 林修远

  # 1. 会用名词（角色专属词汇库）
  # 来自他的身份/职业/爱好/经历
  vocabulary_used:
    high_freq: ["剑意", "悟", "道", "本心", "不屈", "证"]
    mid_freq: ["剑谱", "师门", "恩怨", "红尘", "问心"]
    low_freq: ["情", "爱", "义", "名", "利"]  # 不轻易说

  # 2. 会用动词（行为动词偏好）
  verbs:
    high_freq: ["握", "斩", "问", "悟", "破", "证"]
    mid_freq: ["看", "听", "想", "走", "问"]
    forbidden: ["撒娇", "哭闹", "嘟囔", "嘀咕"]  # 不符合性格

  # 3. 会用修饰（他的语气/口头禅/句式）
  modifiers:
    sentence_length: "短-中（10-20字为主）"
    opening_phrases: ["我曾……", "修道之人……", "你不懂……"]
    catchphrases: ["……又如何", "我若不愿", "我心已决"]
    ending_phrases: ["……罢了", "……而已", "休要多言"]

  # 4. 不会用词（黑名单）
  forbidden_words:
    - "人家"          # 太柔
    - "呜呜"          # 不符合性格
    - "讨厌啦"        # 不符合年龄/性格
    - "宝宝"          # 严重不符合
    - "绝绝子"        # 不符合世界观
    - "YYDS"          # 不符合
    - "emo"           # 不符合
```

### 声音指纹的互换测试

**核心检验**：把不同角色的对话混在一起，遮掉名字，能分辨出谁在说话吗？

- ✅ 能 → 声音指纹清晰
- ❌ 不能 → 还需要打磨

**示例**：

```
A: "我若不愿，天地又能奈我何。"
B: "哎呀妈呀，这可咋整呢。"
C: "依本官所见，此事尚有蹊跷。"

A 是林修远（古风/不屈）
B 是王翠花（东北/市井）
C 是县令（官员/文言）

如果三句遮掉名字仍然清晰 → 声音指纹建立成功
```

### 声音指纹 vs 风格锚点

| 概念 | 范围 | 来源 |
|------|------|------|
| 风格锚点 | 整本书的文风基线 | 作者提供 |
| 声音指纹 | 单个角色的语言特征 | 角色设定 |

**关系**：风格锚点 = 整本书的水彩；声音指纹 = 每个角色的笔触。
两者叠加 = 既有"这本书的味道"又有"每个角色的辨识度"。

## 弧光（Character Arc）— 七步法

**升级自原 skill**：从"弧光三层次"升级到"七步法"，更可操作。

### 弧光七步

```
1. 起点（Who Am I）
   主角相信什么？坚持什么？怕什么？
   例：林修远相信"实力是唯一的尊严"

2. 伤口（What Broke Me）
   哪个事件让主角的信念动摇？
   例：被废修为 + 师父之死 → "实力也会被夺走"

3. 试错（How I Try to Fix It）
   主角怎么尝试恢复旧信念？
   例：拼命修炼想证明自己还是天才

4. 失败（Why It Doesn't Work）
   旧信念为什么解决不了新问题？
   例：单纯追求实力 → 又一次被更强的敌人碾压

5. 中点转折（What I Realize）
   主角意识到什么新东西？
   例："尊严不是靠实力，是靠不屈"

6. 行动（How I Become New）
   主角怎么用新信念行动？
   例：不再追求"最强"，而是"问心无愧"

7. 终点（Who I Become）
   主角变成什么样的人？
   例：从"我若不愿"到"为苍生而战"——保留锋芒，但有了牵挂
```

### 弧光设计 3 原则

1. **起点和终点必须有反差**（反差越大，弧光越强）
2. **每一步必须有"读者可感"的变化**（不能跳变）
3. **弧光不能"否定初心"**（要"升级初心"）

### 弧光 vs 故事线类型

| 故事线类型 | 弧光方向 |
|------------|----------|
| 傻瓜成功型 | 主角获得想要的（保留初心） |
| 麻烦家伙型 | 主角坚持自我到极限 |
| 成长仪式型 | 主角改变信念（升级初心） |
| 金羊毛型 | 主角从"想要"到"需要" |
| 屋里有怪物型 | 主角面对自己内心的"怪物" |

## 人物关系网（升级项，本引擎新增）

**为什么独立**：长篇到 30 万字，人物超过 30 个，没关系网 = 必然 OOC。

### 关系网 5 类

1. **血缘**：父子/兄弟/家族
2. **情感**：爱情/友情/师徒/仇恨
3. **利益**：合作/雇佣/竞争/交易
4. **权力**：上下级/师徒/统治被统治
5. **暧昧**：未明确/暧昧/暗恋/三角

### 关系网维护表

```yaml
relationships:
  - char_a: 林修远
    char_b: 柳如烟
    type: 爱情
    current_state: 暧昧
    development: [初识/并肩/误会/暧昧/表白]
    current_chapter: 35
    tension: 高
  - char_a: 林修远
    char_b: 林修平
    type: 仇恨
    current_state: 仇人
    development: [堂兄弟/陷害/追杀/对决]
    current_chapter: 80
    tension: 极
```

**每 5 万字更新一次关系网**——避免后期人物关系混乱。

## 配角分类（5 种功能）

| 类型 | 数量 | 功能 | 心脏要求 |
|------|------|------|----------|
| 主角 | 1 | 整个故事的中心 | 完整 10 问 + 弧光 |
| 核心反派 | 1-3 | 推动主线 | 完整 10 问 + 弧光 |
| 重要配角 | 3-5 | 主线辅助/感情线/对照 | 6 问 + 弧光 |
| 工具人 | 5-15 | 单事件/单场景 | 2 问 |
| 路人 | 不限 | 填充场景 | 0 问（必要时临时） |

## 反派设计（升级项，本引擎新增）

**原 skill 只有"反派四维度"，本引擎加入"反派弧光"+"反派声音"**。

### 反派 4 维度（保留升级自原 skill）

| 维度 | 检验 | 升级要求 |
|------|------|----------|
| 力量 | 强于主角 | 不可被碾压 |
| 道德 | 不能太坏 | 也要有底线 |
| 认知 | 比读者更聪明 | 不能降智 |
| 魅力 | 有反差感 | 不能纯恶 |

### 反派弧光（新增）

每个核心反派也要有弧光：

```
反派弧光 = 反派的"为什么变成这样" + "他想达到什么"
```

**检验**：
- [ ] 读者看完反派故事，能"理解"他吗？
- [ ] 反派有他自己的"原始动机"吗？
- [ ] 反派有他自己的"伤口"吗？
- [ ] 反派有他自己的"声音"吗？

**示例**（林修平）：
- 为什么：他也是庶出，嫉妒林修远的天赋，被家族嫡系利用
- 想达到：被家族认可，证明自己比林修远强
- 伤口：永远活在林修远的阴影下
- 声音：阴冷/多疑/话里有话

### 反派声音（新增）

反派也有专属声音指纹，不能和主角混：

```yaml
voice_fingerprint:
  character: 林修平
  vocabulary_used:
    high_freq: ["不过", "可惜", "可笑", "你可知", "终究"]
  catchphrases: ["你以为……", "可笑", "终究不过如此"]
  modifiers:
    sentence_length: "中（15-25字）"
    tone: "阴冷/含蓄/话里有话"
  forbidden_words:
    - "啊啊啊"      # 不符合
    - "哼，我才不怕"  # 不符合
```

## 写作时的"心脏驱动"自检

每章写完后问自己：

1. **主角行为是否从"心脏"长出来？** — 换了别人做不了这件事？
2. **角色反应是否过度/不足？** — 是否符合"恐惧"或"欲望"？
3. **伤口是否在跳？** — 是否在某个场景下被触发？
4. **内在矛盾是否在撕裂？** — 角色是否在做自己不愿意但必须做的事？

**如果 4 个问题都是"否"**：本章角色是工具人，需要重写。

## 实战：60 分钟完成主角设计

### Step 1（10 分钟）：L1 简历

填写 7 字段。

### Step 2（20 分钟）：L2 心脏 10 问

10 问逐个回答。

### Step 3（15 分钟）：弧光七步

七步走一遍，确认有清晰变化。

### Step 4（10 分钟）：声音指纹 4 清单

填 4 清单 + 互换测试。

### Step 5（5 分钟）：关系网

列出 3-5 个核心关系。

## 一句话总结

**写人就是写"心脏 + 声音 + 弧光"。** 心脏让角色有内驱力，声音让角色开口就能被认出，弧光让角色活过整本书。3 个齐备 = 角色活；缺任何一个 = 角色工具化。
